## 实现与数据边界

笔记工具行的“浏览”后提供图谱入口，以固定特殊身份 `relatum:graph-tab:v1` 在原标签栏维护唯一图谱页，重复点击仅激活，图谱、正文及浏览结果互斥。图谱占满标签栏下的区域，透明背景显示工作区底色，不再使用遮罩、浮窗阴影、透明度、拖动及尺寸控件；右上角保留生长、舒展、复位及笔记本入口，窄窗另有目录入口。范围以左树选中的笔记本为准；默认本排除 `CustomNotebook`，自定义本只扫描自身子树，未选择本时入口禁用，已有图谱标签显示选择提示。每个已有 Markdown 文件都是节点，包括孤立笔记；标题使用完整文件名 stem，随屏幕缩放比例淡出，悬停恢复当前标题并显示完整路径。点击节点激活已有或新建 Markdown 标签，图谱标签保留；失败继续显示图谱。

进入图谱先等待标题/目录改名、候选、表格及内嵌画布交接，保存当前本待保存正文，失败保留原编辑现场。进入图谱临时收起右栏，图谱侧栏只显示笔记本；返回正文恢复原开关及页签，临时状态不写入原笔记本偏好。特殊标签身份参与已有排序、关闭、快捷键和恢复，文件读取/重命名/保存/外部刷新跳过该身份。

`note_graph.py` 专门解析 Wiki、行内及引用式 Markdown 链接。代码、前言、注释、公式、图片、转义示例不参与，列表、引用和表格中的真实链接保留。跨本、缺失、歧义、外部和自引用不生成关系，同一对笔记合并为无向边。原双链面板和移动重写规则保持原语法。

`GET /api/note-graph?root=…[&signature=…]` 复用现有内存增量索引，只保存引用及元数据，不常驻正文。扫描及失效清理限定当前本；无变化复用结果，只有正文变化且拓扑不变时签名也不变。读取不完整返回 `statistics_incomplete`；初次失败显示错误和重试，后台刷新失败保留同本最后一次正确图谱。快速切本在请求前释放旧本数据，避免旧图谱出现在新本标题下。

后端响应缓存上限为 24 本及估算 16MiB，估算为 `(拓扑 JSON UTF-8 字节 + 128 wrapper/signature 字节) × 2`，属于保守预算而非精确 Python 堆测量，不含已有文档索引；超预算的单项可响应但不驻留。标签测量仅按当前图谱缓存，离屏 DOM 回收池最多 256 项，销毁清空全部测量及 DOM。

笔记图谱不再加载 `graph-window.js`，默认真正查看时才加载共享 GL、引擎及适配器；可选空闲准备提前加载脚本、当前笔记本拓扑、CPU 布局和标题测量，不创建隐藏绘制引擎。切页、浏览结果、离场和页面隐藏立即释放标签、绘制监听器与 GPU/context，迟到响应核对当前本和会话。图谱标签存在或启动准备完成时，前端另以 LRU 保留最多 24 本及估算 16MiB 的正确拓扑、节点坐标、相机与待收敛标记；未布局的准备项只有原始拓扑，布局完成后以位置和标题测量替换，使用相同预算 `(场景 JSON UTF-8 字节 + 128) × 2`，不含活跃绘制资源、DOM 或正文；超大单项不缓存。返回恢复按本视角，拖动后尚未收敛的布局继续有限收敛。成功改名映射受影响会话、作废受影响的后台准备，删除清理，其他本改名不重建当前图谱。关闭图谱标签或 `pagehide` 清空会话，重启后首次打开重新布局取景或消费本次空闲准备好的布局；旧 `canvas:noteGraphViews:v1` 不再读取或写入，坐标不写文件、历史或偏好。共享 `restoreView` 校验有限数值、限制缩放并停止旧相机动画，保持相机零实例失效。

解析压力回归还覆盖约 4MiB 的未闭合语法。数学/反引号闭符与 Markdown 目的地、标题闭符通过预索引查询，失败目标不重复扫描全文尾部。重复 `[x](`、平衡外括号但未闭合 `a.md` 引号标题、未闭合角括号目的地，最终隔离样本分别为 1.873、1.900、1.501 秒，均无引用；1/2/4/8KB 重复 `[x](` 为 0.000636/0.000840/0.001751/0.003316 秒。此前该失败目的地路径在 8KB 已达约 1.32 秒，修复后不再呈平方增长。另三组约 4MiB 未闭合数学及不同长度反引号初轮样本为 1.611/1.563/1.256 秒。此为后端首次或真实变化时的解析，非前端交互帧耗时；最坏大文档首次统计仍会等待。路径的 NFC/大小写折叠碰撞视为歧义，不任意选择目标。

## 标题缩放淡出（2026-10-11）

笔记图谱标题现改为随实际 CSS 屏幕比例淡出：`unit ≤ 0.25` 的标题透明度为 0，`unit ≥ 0.65` 为 1，中间以 `t²(3−2t)` 插值。使用屏幕比例而非单独相机 scale，使窄窗和宽窗遵循同一视觉尺度；DPR 不改变 CSS 阈值。完整文字及 12px 字号不变，不再要求远景常显。

透明度在现有绘制帧更新父层 CSS 变量；悬停只恢复当前标题，相邻标题继续服从缩放透明度。锚点原有入场和邻域明暗保持，跟随既有缩放惯性，无独立 CSS 动画、定时器或 RAF。透明标题保留原锚点和测量缓存，不批量重建 DOM，不修改共享引擎、节点实例或命中规则；原画布和星图不改。
