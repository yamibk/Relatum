# 笔记 Cards

当前行为按 2026-11-04 升级校准。使用统一的新解析器，没有旧版解析分支，也不扫描或迁移已有笔记。

## 编写规则

闭合的 `cards` 围栏仍为唯一入口。每个 1–6 级标题开始一张卡片，井号后的空格可省略；标题之间无需 `---`。也可以用独立 `---` 分卡，这时每段首个非空行可以直接作为无井号标题。空段和末尾分隔符忽略。没有分隔符、也没有任何标题标记的普通文字不推测为卡片。

标题开头可写 `[图标名]` 和 `[!颜色名]`，顺序任意，支持标记连写、大小写和标记内外多余空格。各最多识别一个；遇到未知/重复标记后，余下部分保留为标题。`\[!purple]` 等转义写法是普通标题文字。只有标记没有标题时，该卡片保留原文并提示。

图标为本地 Lucide 子集：`zap/shield/chart/cpu/book/target/bulb/layers/clock/code/check/link`，许可沿用 vendor 的 Lucide LICENSE。颜色直接使用 MarkdownMini 的 37 色白名单及深浅配色，不接受自定义 CSS、URL 或色值。

````markdown
```cards
@style: outline

##[book][!Purple]整理学习笔记
@subtitle: 第三章 · 知识摘要
@badge: 待复习
@value: 3 个核心概念
@footer: 来源：[课程资料](https://example.com)

用自己的话概括**核心概念**，记录疑问与实例。
```
````

## 信息与排版

元信息格式为 `@名称: 内容`，也接受中文冒号或空格分隔。名称和枚举值不区分大小写，展示文字保留原大小写。首张标题之前的元信息作用于整组；标题之后、正文之前作用于单卡。空行不结束元信息区，第一行非空正文开始后，后续 `@` 行全部作为正文。可用反斜杠使元信息行按普通文字显示。

| 作用范围 | 选项 | 默认 |
| --- | --- | --- |
| 整组 | `columns: auto/1/2/3` | auto |
| 整组 | `style: soft/outline/stripe/band` | soft |
| 整组 | `density: comfortable/compact` | comfortable |
| 单卡 | `style: soft/outline/stripe/band` | 跟随整组 |
| 单卡 | `span: full` | 正常列宽 |
| 单卡 | `subtitle/badge/value/footer` | 不显示 |

选项未知、值无效或重复时保留该行原文并提示；首次有效值生效。已知选项的空值（例如 `@subtitle:`）表示清空，整组枚举恢复默认、单卡样式恢复继承；工具清空时保留空声明，避免后方重复声明被误启用。移除颜色/图标时，如果字面标题中的重复标记会被误启用，工具只为该标记补转义。单卡不支持的结构只回退该卡，其他有效卡片继续显示，顺序不变。整组无有效卡片、围栏未闭合或超过既有 256KiB 源码/64KiB 单行限制时保留整组源码。提示中的源码始终转义，不启动公式或其他运行时。

单张有效卡片自动占满组宽，即使显式选了两列或三列。多卡片的 auto/2 在组宽 560px 及以上双列，否则单列；3 在 720px 及以上三列、560–719px 双列，更窄为单列；1 始终单列。默认 800px 正文宽度可以使用三列，列数不改变正文宽度。奇数末卡不自动通栏，`@span: full` 可指定单卡跨完整行。

四种样式为柔和彩底、简洁描边、侧边色条和顶部色带。只有 soft 使用染色背景；其余保留主题纸面，stripe/band 使用色板基色描绘静态色条。缺省颜色使用主题色。舒展内边距/间距为 16/12px，紧凑为 12/8px，圆角 12px。没有阴影、模糊、悬停位移或连续动效。

信息卡按图标、标题和右侧可换行标签、副标题、醒目重点、正文、底部说明排列。缺省字段不占位。标题、元信息和正文共用安全行内渲染；支持段落、逐行有序/无序列表、强调、代码、链接与行内公式。没有图片、表格、块公式、引用或嵌套卡片运行时。原始 HTML/SVG 只显示转义文字。

## 编辑工具与生命周期

正文右键“插入”提供 Cards，生成一张卡片并进入源码编辑。实时预览单击选整组，右上角“样式”打开原生模态面板；双击/Enter 编辑源码、Esc 收起不变。阅读与引导仅展示渲染结果。

面板可选择整组或某张卡片，分别调整整组布局/样式/间距，以及单卡颜色/图标/样式/宽度/可选信息。列数显示为“自动、单列、最多双列、最多三列”，表示每行最多排列的卡片数，提示明确点击应用后生效及单卡自动通栏。各目标共用本次会话草稿，切换目标不丢草稿；取消、关闭或离场丢弃草稿，点击应用通过一个 CodeMirror 事务修改对应源码，一次撤销恢复全部目标。未触及的正文、标记、未知选项和引用前缀不重写。中英文引导的布局示例包含前三张正常卡片及第四张通栏总结；引导栏窄时自动减列，复制到正文即可查看三列效果。

工具等待中文候选完成再应用；切文档、正文变化、模式切换、工作区离开、语言变化、隐藏、最小化和 pagehide 关闭工具并拒绝迟到提交。原生输入候选期间的应用等待 compositionend。下拉复用 review-controls，Esc 优先关闭下拉，其次关闭面板。

## 接口、资源与数据

- `assets/note-cards.js` 保留 `RelatumNoteCards.parse/render/attach`。parse 返回有效性、卡片、整组设置、源码范围、元信息范围、顺序段落及诊断。卡片保留 `title/icon/color/body` 并新增可选信息与源文位置。`patch(source,target,fields)` 返回局部修改列表，target 为 `group` 或卡片索引，非法输入返回 null；范围使用 JavaScript 字符偏移，调用者传入 CRLF 时映射回原字符串。
- `assets/note-cards-tools.js/css` 仅首次点击样式工具时加载；所需 review-controls 也只在缺失时加载。加载失败显示可重试入口，迟到资源不得唤回旧面板。资源归 notes 权限。`note-cards.css` 仍由首次有效渲染请求。
- 实时、阅读、引导和独立 Markdown 窗口使用同一核心；笔记宿主显式提供围栏渲染，其他 Markdown 宿主仍按普通代码显示。独立窗口复用编辑工具及浅深色语义。
- 原有围栏三态、剪贴板、边界删除、中文输入交接及高度测量继续复用。Cards 仍有独立块 ID 和最多 32 项数值高度缓存。几何变化使原高度图失效，选择变化复用 DOM。
- 真实公式才按需请求 MathJax；可见性、销毁和版本保护继续生效，没有新增轮询、观察器或常驻 RAF。搜索使用真实源码偏移，卡片标题不进大纲，标签/双链仍排除围栏内容。
- Markdown 是唯一持久化内容，无新增后端接口、数据文件、配置键或迁移。中英文引导同时展示容错写法、颜色、信息卡与布局示例，预览/复制共用源码。
