# 笔记正文输入与大表格验收 · 2026-10-14

本轮只调整笔记 Markdown 正文及其表格输入。Markdown 仍是唯一事实来源，沿用原 API、原子保存、修订校验和父 CodeMirror 历史；用户笔记、附件、配置和左右面板未改动，没有新增运行依赖或持久化字段。

## 行为

- 普通段落、标题、引用正文的 Tab 在光标处插入真实 `\t`；实时预览和源码模式一致。Shift+Tab 优先撤去光标前的制表符，否则反缩进。非空选区仍整行缩进，代码/公式/前言等源码保留结构缩进。行首制表符依然可能形成 Markdown 缩进代码。
- 列表 Tab 按前一同级项的内容列移动当前项及子项；Shift+Tab 退一级。第一项不强行缩进，最外层不删除标记；空项 Enter 即退一级或退出，保留引用前缀并生成真正的段落分隔。
- 五种行内格式可重复切换，部分取消保留其他文字及嵌套格式、链接，多选区在同一格式中合成一次事务。空选区不插示例字，可开始输入、移除空标记或退出格式。代码跨度所需的反引号长度和填充空格不泄漏到取消格式后的文字。
- 格内快捷键共用正文变换及本机绑定；取消的默认键不会恢复生效。父编辑器仍负责撤销、保存和输入法交接。
- `apple\t苹果`、末尾空列和多行 TSV 从正文复制后按格粘贴；单格编辑只替换所在数据行，其他格保持原 DOM。

## 实现边界

`markdown-table.js` 提供共享行序列化。单格通知验证旧文档/模型、表格身份、行列、源码、唯一变更及选区映射；无效通知回到完整解析。模型只复制行索引与变化行，源码仍实时提交到父编辑器。

实时预览的顶层网格使用 [Lezer 公开叶解析器接口](https://github.com/lezer-parser/markdown#user-content-blockparser) 保留块边界，单元格由已有独立渲染器解析。源码模式、标题扫描、代码和引用内语法保持完整解析；切换不改正文或历史。隐藏在活动 textarea 下的片段退出时再更新，首次失效清理公式并使旧异步片段失效；原生输入宿主始终保持挂载和有效几何。真实布局/视口变化继续校准，纯位置映射复用表外装饰。

## 三轮同机对照

基线为 `fafc085`，从 Git 读取三个旧资产到测试服务器内存，不回退工作区。Node 22.21.0、Edge 155.0.4283.45，相同字体、CSS、1280×900 视口和合成网格，旧/新交替三轮；每轮在第二行第一格用原生 Chromium 输入协议逐字输入 30 个字符，间隔 20ms，剔除前五次预热。计时从原生 input 捕获到该输入处理完成，包含同步提交、语法和布局开销，排除协议往返及后续显示帧。

表内数字取三轮统计量的中位数，单位 ms。逐次样本、三轮统计和计数保存在 `note-input-2026-10-14.samples.json`。

| 规模 | 旧中位数 | 新中位数 | 降低 | 旧 p95 | 新 p95 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 400×10，4000 格 | 12.4 | 0.9 | 92.7% | 16.7 | 2.1 |
| 800×10，8000 格 | 23.7 | 1.2 | 94.9% | 32.7 | 2.3 |

每轮 30 次输入：旧版遍历单元格分别 120000/240000 次、整表 parse API 60 次、整表 serialize API 30 次；新版均为 0。旧版最大替换范围 35770/72570 字符，新版最多 100 字符，仅一行。新版未编辑格内容变动为 0，原生输入节点和代表性未编辑片段身份保留。计数只在测试注入。

本机不同运行状态的绝对延迟有波动，因此仅列完整最终实现的交替对照，不把数值推广为其他机器的固定延迟、整页帧率或所有表格操作的耗时。语法处理、源码快照、真实尺寸变化和结构操作仍有成本。
