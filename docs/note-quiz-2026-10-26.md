# 笔记交互选择题

## 使用方法

在笔记中填写一个闭合的 `quiz` 围栏：

````markdown
```quiz
刚接通电源时，电流是多少？

- [ ] 0 mA
- [x] 6 mA
- [ ] 12 mA

---
由 $I=U/R=12/2000$ 得到。
```
````

每个围栏是一道单选题，至少两个非空选项，恰好一个 `[x]` 或 `[X]` 声明正确答案。题干与解析可多行，选项每项一行，选项后的独立 `---` 引出可选解析。支持强调、行内代码、安全链接与公式；题内不启动图片、图表、内嵌画布或表格。普通任务列表行为不变。

实时预览和阅读模式均可作答。题块使用淡描边和近透明的黑白底色，随深浅主题适配；单选控件不绘制额外焦点圆圈，键盘焦点用选项行的淡底色反馈。未答时没有答案或反馈图标；选择后显示正确答案和解析，正确为绿色圆圈勾，错误为中性灰色信息圆圈，两者使用固定 SVG 线条而非文字字符。改选不重建反馈文字，重做恢复未答。实时预览的编辑入口在悬停或聚焦时出现，也可用现有源码模式编辑。“重做”和“编辑题目”使用 Relatum 的 `--font-ui` 界面字体、线性图标和轻量圆角按钮，复用笔记控件的悬停、按下与焦点颜色；系统低动态和笔记关闭动效时移除按钮过渡。

答题不会改写 Markdown、触发保存或进入撤销历史。答案在应用当前会话内跨笔记、跨模式保留，刷新或重启清空；最多保留 2048 条，超出淘汰最久未使用记录。题目内容发生编辑或外部正文替换时清除旧答案，其他正文编辑映射题块范围。应用内文件/目录移动沿用现有路径映射。

启动器中的“笔记选择题”是 `notes` 下默认启用的 `notes.quiz`，不依赖 AI、图谱、Mermaid 或内嵌画布。关闭时显示普通源码，且专属资源不可直接读取。旧启动器配置未填写此字段时沿用清单默认值；启动不重写配置。

“笔记设置 → 引导 → Quiz”提供基本题与公式题的效果、源码和复制；中英文的引导选项和面板标题均为 Quiz。沿用 `canvas:noteGuideTopic:v1` 的新值 `quiz`，重置仍回到 Callout。引导使用独立临时答案，关闭功能时仍可复制源码。

## 模块和接口

- `note-quiz-core.js` 不依赖 DOM、编辑器、存储或网络。`parse(source)` 返回 `{valid,error,model}`；模型含题干、选项、正确项、解析和内容指纹。`evaluate(model,index)` 返回 `{answered,correct}`。
- `createSession()` 管理有界内存记录，提供读取、设置、范围映射、文档校验和路径迁移。只保存指纹、范围和选择，不保留正文或 DOM。文档指纹复用编辑器快照时机，同一个不可变文档不因滚动或选区重复计算。
- `note-quiz.js` 的 `attach(root,options)` 返回 `update/suspend/resume/destroy`；宿主注入会话、范围、身份检查、文字渲染、公式排版、布局通知和编辑/链接操作。该模块不了解 CodeMirror 和工作区实现。
- `note-quiz.css` 只限定题块内部样式，使用既有主题变量，无持续动画或背景模糊。
- `note-live-editor.js` 保留薄接入层，统一加载资源、可见挂载、公式交接和生命周期；独立题块 Widget 隔离作答事件。阅读与引导共用同一入口，未闭合/超限围栏维持代码，闭合但无效的题块展示源码与语法说明。
- `MarkdownMini.renderResult(source,{renderFence})` 可选回调接收 `{language,source,from,to}`；返回字符串替换该闭合围栏，返回 null/undefined 维持原逻辑。范围以调用方源码 UTF-16 位置为准，笔记阅读映射标题、frontmatter 和画布占位的偏移。其他宿主不传该回调。
- `renderLabelResult(source,{links:true})` 显式允许安全链接；旧调用默认行为不变。图片、原始 HTML 和图表不在此入口执行。

## 布局与光标

实时预览的 Quiz 复用 `compactBlockProjection()` 的紧凑投影与 `mapBlockProjections()` 边界修复。视觉投影覆盖围栏的边界行，光标原子范围仍只对应真实源码，不吞并相邻换行；候选期间只映射边界，保持原 widget。源码中的真实空行完整保留，可直接点击、输入、保存及撤销/重做；没有空行时不自动向 Markdown 写入段落。

实时预览外层仅使用上下各 4px 的测量内边距，内部题卡外边距为零；阅读与引导仍使用各自原有间距。默认 16px 字号下，两道相邻且没有空行的题卡间隔从约 84px 降至 8px；一个真实空行增加一个正文行高。卡片内部留白、描边、底色、按钮和图标不受影响。不修改 `.cm-line` 高度、行高、CodeMirror vendor 或其他语法的边界策略。

作答/重做及公式加载可能只改变 widget 内部高度，而编辑器的最小高度保持不变，此时单独 `requestMeasure()` 不一定使 CodeMirror 的高度图失效。Quiz 的布局通知在测量阶段读取实际高度，在测量结束后的微任务中通过内部 `quizLayoutEffect` 更新该题的高度估计与 decoration；`updateDOM()` 交接原控制器、题卡和反馈 DOM，不重建答案、不写正文或历史。每篇当前文档最多保留 64 条数值高度，切文档清除；迟到测量核对身份、可见状态与候选交接，不使用持续轮询或 RAF。

## 资源与生命周期

普通笔记和纯源码模式不请求专属资源；实际可见的题块才请求三个本地资源并创建交互 DOM。加载前使用空白占位，不闪现带正确答案标记的源码；加载失败才展开源码与重试入口。阅读只给可见题块安装交互，百题文档不一次性创建全部单选控件。关闭功能后不请求资源，后端直接读取返回 403。

题块只局部更新选择与反馈，不重绘整篇笔记。公式仅在相应内容显示后加载 MathJax；隐藏答案中的公式不提前触发加载。隐藏、原生最小化和 pagehide 暂停任务，离场/销毁清理观察器、事件与公式记录，迟到任务核对身份。加载失败保留源码并允许重试。无新增 HTTP API、数据文件、Worker、全局子树观察器或持续 RAF。

## 验证

专项入口：

```text
node tests/note-quiz-core-regression.js
node tests/note-quiz-browser.js
node tests/note-quiz-layout-browser.js
node tests/note-live-editor-regression.js
node tests/note-live-presentation-browser.js
node tests/note-settings-browser.js
node tests/feature-profile-browser.js notes-quiz notes-quiz-off notes-quiz-parent-off
python -B -m unittest tests.test_feature_profile tests.test_launcher_native
```

浏览器沿用 `RELATUM_PLAYWRIGHT`、`RELATUM_EDGE_PATH`，真实服务另用 `RELATUM_PYTHON`；单测设置一次性 `RELATUM_DATA_ROOT`。测试、截图和报告均使用临时目录。回归包含原 Markdown、实时编辑器、输入和 Mermaid 测试。浏览器模拟最小化不等于原生桌面包验收；本次不重新打包，也不以浏览器候选事件替代微软拼音人工验收。

布局专项覆盖 32 组深浅/宽窄/字号和起止/连续/真实空行/公式夹具、12 组作答反馈后的鼠标落点与历史、4 组 Chromium 原生候选确认/取消，以及 Mermaid、表格、Callout、分隔线和代码混排、32 题长文滚动后的文字定位。设置浏览器的完整模式另验证真实空行输入、保存、撤销、重做及恢复原文的磁盘字节；静态 StateField 回归验证 Quiz 首尾候选插入、替换、取消、多边插入与删除，同时保留原 Mermaid 的边界策略。
