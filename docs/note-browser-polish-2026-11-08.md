# 笔记浏览与搜索面板精修

## 展示与范围

左侧浏览导航和中央最近文件、标签结果、画布列表、搜索共用轻卡片布局。默认、Claude、Sky、Apple 使用原有字体与主题颜色；正文编辑器、右侧笔记本栏和顶层工具栏不调整。没有新增字体、第三方依赖、持久化字段或后端接口。

- 内容列最多 880px，标题、控件、列表和状态对齐；宽窗始终保留既有右栏宽度及 8px 间隔，避免内容被覆盖，右栏开关不改变列表宽度。窄窗遵循原覆盖侧栏行为。
- 页标题 24px/600，卡片标题 15px/600，摘要 14px，辅助信息 12px；卡片圆角 14px、间距 10px、内边距 18×20px，使用主题表面、细边界与极轻阴影。
- 摘要最多两行，空摘要不占位；前三个标签后显示剩余数量。普通位置只显示笔记本和文件夹，整卡悬停与键盘聚焦通过原共享提示查看完整路径及省略标签，并保留可访问描述。路径命中使用完整原路径和原 UTF-16 高亮，不在简写后重新计算偏移。
- 左侧独立呈现悬停、当前项和键盘焦点；Apple 蓝/灰导航选中色继续使用原独立偏好。搜索框 46px、筛选控件 34px，画布筛选为紧凑分段按钮，刷新保留独立入口。
- 加载、空结果、错误重试、索引状态及分页拥有稳定宿主。画布统计不完整时移除不可信旧条目和计数，修复原先保留旧结果却显示统计失败的情况。

## 交互及资源

`assets/note-browser.js` 将最近、标签、搜索的结果宿主统一为常驻的标题、控件区、列表、状态及分页。按路径协调行，更新动作读取最新元数据；标题、摘要、标签和路径分别比较展示身份，未变化的内容节点不重建。画布仍使用原引用状态、分页、展开、缺失提示、右键及资源管理器操作。

超过 200 项继续复用 `RelatumWindowedList`，登记 `gap:10` 和变高估计，避免 CSS 间距与窗口列表的累计高度不一致；保留焦点项、已有分页、返回锚点及原子多页刷新。笔记本位置来自宿主已有目录元数据，不额外扫描正文或请求目录。

主动切换浏览页面时只播放一次 180ms、4px 淡入位移，不等待动画再提交数据。相同页面重选、输入刷新、分页、后台失效、窗口重挂载和返回不重播。卡片及按钮约 120ms 颜色、边界和按下反馈，无悬停抬升。筛选展开 180ms、弹层进退场 160/120ms 沿用原控制器。

快速切页、打开搜索弹层、切回正文、隐藏、原生最小化、销毁及低动态变化取消当前入场。系统与笔记自身的低动态设置均生效，不增加持续 RAF、轮询、模糊或常驻 `will-change`。搜索查询、输入法、保存交接、修订检查和命中定位继续使用原协议。

## 隔离验证

使用现有宿主的 `RELATUM_PYTHON`、`RELATUM_PLAYWRIGHT` 和 `RELATUM_EDGE_PATH`，测试数据、偏好及浏览器配置均隔离。

```powershell
node --check assets/note-browser.js
node tests/note-theme-regression.js
node tests/note-browser-browser.js
node tests/note-ui-browser.js
node tests/note-search-browser.js
node tests/note-folder-picker-browser.js
node tests/note-sidebar-browser.js
node tests/note-canvas-browser-discovery.js
node tests/note-visibility-browser.js
```

新增 UI 验证覆盖四主题深浅、Apple 蓝/灰选中色、中英文与窄窗、长标题/路径、多标签、原始路径高亮、编辑器及右栏保留、动画取消、返回不重播，以及闲置无持续 RAF。浏览回归增加最近分页的宿主、行、标题文字及标签节点身份，另检查空摘要不占位。截图可通过 `RELATUM_ARTIFACT_DIR` 留存。

已有日历和文件夹测试在切换系统低动态时存在时序竞争：控制器会主动关闭当前浮层，旧测试随后直接点击或对已关闭菜单滚动。现在先等待真实关闭，再在低动态下重开验证。UI 夹具清理保留临时根边界检查，并对 Windows 退出时短暂文件占用做有限重试。

本次验证为本机 Edge/Chromium 的源码服务，未重新打包；不将其等同于发布 EXE/WebView2 或真实微软拼音的人工验收，也不把闲置 RAF 计数称作整机性能提升。
