# Relatum 大画布性能升级验收

日期：2026-09-05。范围：1000–3000 节点画布及共享翻译层、起步页回归。

已完成内部机制升级：保留 DOM 文字编辑、Canvas 静态连线与活动 SVG；HTTP API、`.canvas` 格式和离线运行方式不变。没有引入前端框架、npm 构建链或运行时网络依赖。

## 实现

- 翻译观察器归并新增子树和重复记录，整棵跳过正文、连线几何、手写和小地图节点。全局语言状态仅在初始化和语言切换时同步；用户输入值保持原样，输入提示仍可翻译。
- 新增 `assets/canvas-changes.js`，保留约 50 步完整历史快照，恢复时按 ID 比较并同步差异。未变化的节点 DOM、附件运行时、记录对象和连线几何继续复用；只刷新受影响的目录、折叠和任务簿派生状态。类型转换的标记随原位渲染更新，撤销时重建不兼容的内容；快速删除后撤销会清理尚未结束的离场副本。
- 连线用已有 512 单位空间网格筛选候选，通过 `Path2D/isPointInStroke` 按逆叠放顺序命中。静态 SVG 路径和命中条不挂入文档，拖动只挂载相邻活动连线；保留 SVG 能力回退。曲线边界涵盖控制点凸包，标签保留真实路径中点，图片导出按完整数据补齐路径。
- 批量挂载节点后统一测量，缓存节点相邻连线、内容边界、视口与小地图尺寸。相机移动只变换小地图节点层，停止后校准点尺寸。抓手和连线光标使用局部命中面，避免光标继承引发数万后代的样式重算。
- 双屏关闭、退场以及迟到的 iframe 回调不再读取外观。打开时只对背景来源变化按帧合并为一份外观数据。
- `?perf=1` 分别记录数据就绪、核心 DOM 就绪、揭幕后帧回调、可交互和操作收尾时间；普通页面没有新增性能采样循环。`loadMs` 现在对应可交互时间，尚未就绪时为 `null`。

## 测量口径

Windows，本机无头 Microsoft Edge 152.0.4191.62，1440×900，DPR 1，初始缩放 100%，相机中心 (330, 280)。每种规模 5 次新浏览器进程冷启动、5 次同页热启动；冷启动重置浏览器缓存，不清空操作系统磁盘缓存。测试服务通过 `RELATUM_DATA_ROOT` 使用独立临时数据目录。

1200 节点夹具有 2359 条连线；3000 节点夹具有 2970 条连线。操作覆盖局部缩放、25% 缩放视图、空格平移、单节点拖动与撤销。25% 是现有最小缩放，不表示全部 3000 节点同时可见；结果不能直接外推到大量公式或重附件同时可见的画布。

可交互时间从导航起点计时，经过揭幕后的动画帧及其后的事件循环机会，涵盖初始化观察器和布局工作；它不是 GPU 硬件呈现时间。操作 `settledMs` 包含同步执行以及随后的帧与事件循环机会。旧方案中的“打开长任务阻塞”与现在的“可交互时间”不是相同指标，因此不据此计算提升百分比。

原始记录：[启动与操作基准](performance-2026-09-05.benchmark.json)、[浏览器行为回归](performance-2026-09-05.regression.json)。

以下采用最终源码的完整五轮结果。启动单元格为“中位数 / 最慢”，操作指标取五轮中最大值。

| 指标 | 1200 节点 | 3000 节点 | 方案目标 |
| --- | ---: | ---: | --- |
| 冷启动可交互 | 1.124 / 1.275 s | 2.208 / 2.392 s | ≤1.5 / 3 s |
| 热启动可交互 | 0.835 / 0.921 s | 1.688 / 1.915 s | ≤1.5 / 3 s |
| 局部缩放帧间隔 P95 | 17.0 ms | 17.0 ms | ≤20 ms |
| 空格平移帧间隔 P95 | 16.9 ms | 16.9 ms | ≤20 ms |
| 单节点拖动帧间隔 P95 | 17.0 ms | 17.0 ms | ≤20 ms |
| 25% 视图缩放帧间隔 P95 | 16.9 ms | 17.0 ms | ≤33 ms |
| 拖动收尾 | 24.3 ms | 29.7 ms | ≤100 ms |
| 单节点撤销收尾 | 33.1 ms | 66.4 ms | ≤100 ms |

本组场景达到上述目标。3000 节点冷启动在 1.416–2.392 s 之间波动；拖动采样仍出现两次约 50 ms 的单帧，P95 达标不表示完全没有偶发长帧。静态状态挂载的 SVG 连线路径/命中条为 0；被测节点拖动时分别只有 3 / 1 条活动 SVG 线，结束后回到 0。

## 功能与测试

- 浏览器行为回归通过：连线叠放命中、选择切换、拖弯、双击命名、右键菜单、曲线中点、完整连线路径导出；节点类型转换、撤销、重做及未变化记录/DOM 复用。
- 覆盖分组与导图折叠、导图布局、任务簿完成/撤销/重做；80 张图片、40 篇 Markdown、12 份 PDF 的视口生命周期，以及撤销其他节点时的重内容复用。PDF 夹具每份 120 页，Markdown 每篇约 116 KiB。
- 覆盖中英文切换、合成 composition 事件与中文插入、DPR 2、减少动态效果、深色语义、SVG 回退、双屏背景更新及参考节点选择。1000 个几何对象插入产生 0 次全局语言属性重写；双屏关闭时 0 次无效外观读取，打开后 20 次背景写入合并为一份外观数据。
- 起步页七个入口与快速反向切页的 P95 帧间隔约 17 ms。少量单帧约 33 ms，未改动既有翻页机制。
- 用户提供的《数学建模经验》在隔离副本上验证：46 节点、37 条连线，可交互约 866 ms，缩放 P95 16.9 ms，成功生成 6872×3216 PNG。原文件 SHA-256 保持 `EFB3CCF8439A255725B73A7EC6927E5E9F97A266D899B15BD3DA2527B7FAF28A`。
- Python 单元测试 247 项通过；Node 单测与契约脚本 60 个中 55 个通过。新增变更集合回归及相关性能契约通过，JavaScript 语法检查和 `git diff --check` 通过。

以下 5 项 Node 契约失败均已在修改前的 HEAD 上复现，属于已有源码与契约不一致，本轮未修改对应功能：

## 复现

1. 生成隔离夹具：`python tests/generate-performance-fixtures.py <隔离目录>`。生成器拒绝仓库根目录及其子目录。
2. 将 `RELATUM_DATA_ROOT` 指向该目录，运行 `python -B app.py --no-browser --port 8766`。
3. 在另一个终端设置 `RELATUM_PLAYWRIGHT` 为测试主机已有 Playwright 模块的绝对路径，`RELATUM_EDGE_PATH` 为 Edge 可执行文件路径。
4. 运行 `node tests/canvas-browser-performance.js http://127.0.0.1:8766 <隔离目录> <输出.json> all`。也可分别使用 `regression` 和 `benchmark`；基准默认每种规模 5 轮。

功能测试拦截保存到浏览器替身，避免累积改动夹具；基准保留正常 HTTP 缓存与真实隔离服务。测试工具不是应用依赖。
