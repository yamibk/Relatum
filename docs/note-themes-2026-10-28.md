# 笔记内置主题

外观分类顶部依次提供“默认 / Default”、“Claude”、“Sky”和“Apple”，保留用户当前选择。
主题覆盖整个笔记工作区及所属浮层，深浅色继续由全局开关控制。
笔记工作区激活时，顶部公共导航和独立专注窗口按钮同步笔记主题；
切到其他工作区恢复原有配色，全局设置保持独立。

## 入口、偏好与扩展

- `assets/note-theme.js` 在 head 读取 `canvas:noteTheme:v1` 并设置 `html[data-note-theme]`。
  缺失/无效值使用 `default`，启动不写默认，不清理无效值。
- `RelatumNoteTheme.list()` 返回冻结的内置主题登记表；`read()` 返回当前 ID。
  `apply(id, {persist=true})` / `reset()` 返回成功布尔值，存储失败不发布状态。
  当前稳定 ID 为 `default / claude / sky / apple`，Sky 与 Apple 的中英文名称各自相同。
- 真正变化前后分别发布 `relatum:note-theme-beforechange` 与 `relatum:note-theme`，
  detail 为 `{previous,current}`。相同主题不产生事件或布局工作。
- 新主题增加登记项及 `assets/note-theme.css` 中的作用域样式；没有外部主题加载器。
  两个文件及新增字体受 notes 资源权限控制，偏好沿用桌面 `canvas:` 快照。
- 外观分类恢复和全部笔记设置恢复调用主题 reset；全局设置恢复不改变笔记主题。

主题下拉的 `.note-theme-popovers` 是 dialog 内的绝对定位宿主，`inset:0` 且
`pointer-events:none`，实际 `.review-choice-popup` 恢复 `pointer-events:auto`。
它与现有 AI / LaTeX 浮层一样不参与网格排布，不占据额外行，也不挡住设置控件。
共享设置外壳用显式区域安排分类栏和主区：宽屏一行两列，分类栏及主区铺满弹窗高度；
720px 以下为顶部分类区与下方主区两行，主区占满剩余高度。
Sky 主区标题、内容及页脚沿用同一纸面色，雾蓝分类栏延伸到底部圆角，卡片保持独立浅色表面。

## 表现与资源边界

Claude 浅色参考用户提供的 Anthropic 官网截图，以 `#faf9f5` 为暖白纸面，
顶栏、正文、文件树和右栏统一底色，不再将侧栏铺成整块黄灰色。
设置卡片同样使用纸面底色与浅色细边界，白色 `#fff` 留给浮层和主题下拉触发器；
悬停为 `#f2f1ed`，选中为 `#eae9e4`，代码底为 `#f3f2ee`。
浅色边界、弹窗遮罩、菜单阴影与顶栏选中块阴影均减轻，保留原尺寸及交互。
深色以用户 2026-10-29 提供的 Claude 对照截图取样：主内容为 `#191919`，
选中行底色为 `#404040`。按用户要求简化大面积色块，文件树、顶栏、正文和右栏统一
使用 `#191919`；菜单、卡片与代码底统一 `#242424`，悬停为 `#2a2a2a`，
去掉原先各面板偏黄绿的黑色差异。强调色 `#d97757`。
浅色设置弹窗的标题、正文、页脚与侧栏统一使用暖纸底，以细边界和留白区分卡片；
菜单、确认及图片文字工具栏使用浮层表面，避免主面板仍为纯白或旧墨绿色。
顶栏品牌、工作区选中块、齿轮、窗口按钮均使用局部主题变量；
关闭按钮保留红色危险反馈，沉浸背景沿用渐隐，不使用背景模糊。
正文链接保持蓝色，危险、成功及用户指定颜色仍沿用自身语义。
文件染色的显式颜色行保留原背景/悬停/选中规则。

正文及文件名标题的英文使用 Source Serif 4，中文沿用微软雅黑与 Noto Sans SC；
界面继续使用原无衬线字体，源码/代码保留等宽，MathJax 保留数学字体。
Mermaid 显式使用原 Open Sans/中文后备栈，使主线程和既有 Worker 测量一致，
更换正文主题不重新生成 SVG。图谱的字体、引擎、镜头和布局不变。

字体采用 Adobe 官方固定提交 `80d3f8894c09c937bebfa9011247d2e1c79fd6f4`
中的两份可变 WOFF2，合计 755088 字节；不修改字体文件。
来源、校验和及 SIL OFL 1.1 许可在 `assets/fonts/source-serif-4-*`。
默认主题不请求新字体，运行时没有 CDN、外部字体或网络依赖。

下拉复用 `RelatumReviewControls`，位于笔记 dialog 内、滚动裁切区外，
沿用键盘、焦点、勾选和有限动画；关闭/离场/隐藏/最小化/语言/低动态切换收起。
主题切换只改变 CSS 与必要测量，不重建编辑器，不改正文或历史；
可见文本位置在切换及字体完成加载后校准，迟到任务核对文档、视图与可见会话。
沉浸背景保留原透明度及几何，不引入模糊、观察器或常驻 RAF。
浅色侧栏沉浸层的 RGB 与纸面统一为 `(250,249,245)`，深色层统一为 `(25,25,25)`，
仍保留原透明度以呈现环境背景。浅色打磨仅作用于浅色，深色配色和交互保持原样。

## Sky

Sky 提供完整的浅深色配色，参考天光与云纸的层次。源码集中于原主题样式，
不加载外部主题、框架、图片或字体，也不新增持久化字段。

| 角色 | 浅色 | 深色 |
| --- | --- | --- |
| 正文基色（渐变回退） | `#f8fbff` | `#162338` |
| 两栏、顶栏和标签栏 | `#e8eff8` | `#101a2a` |
| 菜单、卡片与浮层 | `#ffffff` | `#1d2d44` |
| 正文 | `#27364b` | `#dde7f5` |
| 次要文字 | `#5d6e84` | `#a4b4cb` |
| 链接与焦点 | `#2f6fa9` | `#8abff0` |
| 悬停 / 选中 | `#dfeaf8` / `#d2e4fa` | `#20324a` / `#29415f` |
| 代码底 / 边界 | `#eaf1fa` / `#d7e2ef` | `#101b2d` / `#2c3b52` |

Sky 浅色普通背景的正文采用静态
`linear-gradient(135deg, #edf4fc 0%, #f3f7fd 48%, #e9f1fc 100%)`。
渐变只绘制在 `.note-document-pane`，面包屑和 `.note-document-body` 使用透明底，
文件名标题、实时预览、源码和阅读共用一张面板背景；背景随面板尺寸铺满，正文滚动时不重复或移动。
两侧栏、标签栏、设置面板和正文内的代码/引用/用户色块沿用原表面。
深色与沉浸模式不使用这层渐变，保留原有底色和透明度。

正文及文件名标题使用既有 Open Sans / Noto Sans SC，后者优先承接中文；
界面使用 Segoe UI / Noto Sans SC。保留 100%=16px 与响应式宽度，实时预览和阅读行高均为 1.8。
标题字重 700，H1–H6 比例为 `2/1.6/1.3/1.1/1/1`，H1 隐藏底线，H2 保留细线，H6 使用次要色。
代码及源码保留等宽，MathJax、Mermaid 与图谱保留字体及测量边界。
切换后的字体等待在原宿主中按主题处理，晚到结果仍核对文档、视图与可见会话。

工具按钮 8px、普通卡片及代码块 10px、菜单 12px、设置卡片 14px 圆角。
浮层用不透明表面和轻阴影，顶栏沿用静态渐隐，不采样背景。
局部悬停、焦点颜色仅过渡 140ms，系统或笔记低动态均取消，开合复用原控制器。
沉浸壳/两栏/正文/工具栏透明度浅色为 `.48/.74/.80/.70`、深色为 `.66/.78/.84/.76`，
颜色取自对应 Sky 表面，保留原外壳形状。

语法使用已有代码与数学变量，浅色以蓝、灰紫、青绿、棕色区分函数、关键字、字符串和数字，
深色使用柔亮版本。引用采用轻底与竖线，表格首行在实时预览和阅读模式均显示淡蓝表头；
阅读仍复用原普通单元格结构，不修改 Markdown 或表格语义。
表头的单元格编辑器同样使用 700 字重，显示态与编辑态的字符宽度保持一致，
避免居中/右对齐英文在点入或拖选时跳到相邻字符。
六色高亮只改变本主题的透明色，解析、emoji 标记及菜单行为保持一致。
普通 Callout 沿用类型色并与纸面混色，显式颜色块不混色；
文件染色的背景/悬停/选中、笔记本图标颜色、图片文字颜色以及危险/成功反馈保留各自含义。

## Apple

Apple 使用 macOS 原生应用的中性表面、细分隔线、轻阴影和克制蓝色反馈。
参考 Apple 官方配色指南：https://developer.apple.com/design/human-interface-guidelines/color 。
不新增外部主题加载器、偏好字段、框架或运行时网络请求。

| 角色 | 浅色 | 深色 |
| --- | --- | --- |
| 正文纸面 | `#ffffff` | `#1c1c1e` |
| 两栏、顶栏和标签栏 | `#f5f5f7` | `#242426` |
| 菜单、卡片与浮层 | `#ffffff` | `#2c2c2e` |
| 正文 / 次要文字 | `#1d1d1f` / `#6e6e73` | `#f5f5f7` / `#aeaeb2` |
| 链接与强调 | `#0066cc` | `#0a84ff` |
| 分隔线 | `#d2d2d7` | `#3a3a3c` |
| 表头 / 隔行底色 | `#f0f0f2` / `#fafafa` | `#2c2c2e` / `#222224` |

界面、正文、文件名标题及 AI 回答英文使用本地 Inter 4.1，中文复用 Noto Sans SC。
字体来自官方 tag `v4.1` 的固定提交 `e3a3d4c57d5ecc01453a575621882a384c1995a3`，
正体与斜体可变 WOFF2 合计 740216 字节，不修改文件；来源、SHA-256 和 OFL 1.1
许可见 `assets/fonts/inter-*`。两份字体登记到 notes 权限，其他主题不请求 Inter。
切换按原有文档、视图与可见会话检查等待 Inter 和 Noto Sans SC，字体迟到不会恢复旧阅读位置。
正文 400、重点控件 500、文件名标题 650、H1 700、H2–H6 600；
实时预览和阅读正文行高均为 1.75，标题比例为 `2/1.6/1.3/1.125/1/1`，H1/H2 无底线。
保留用户字号、正文宽度和原表格单元格编辑器的 1.55 行高。
表头编辑器保持与显示态相同的 600 字重，避免居中/右对齐英文在进入编辑时改变文字命中位置。
源码/代码、MathJax、Mermaid 主线程/Worker 和图谱字体及测量方式保持原边界。

工具按钮 8px，内容卡片/代码块/表格外角 12px，菜单与设置卡片 14px；
设置弹窗保持原尺寸并使用 20px 圆角。设置主区浅灰/深黑，分类栏铺满到底部，
卡片与菜单为独立表面，下拉仍位于同一 dialog 的裁切区外，不参与网格排布。
实时预览与阅读表格统一灰表头、600 字重、细网格和轻微隔行底色，选区/编辑/拖动使用蓝色。
通过外缘单元格圆角保留表格宿主的 `overflow:visible` 与原横向滚动，
不裁切行列手柄、添加按钮、拖动标记及单元格编辑器，不改 Markdown 数据或表格结构。

引用、代码、Callout、Quiz、六色高亮、图片选择框、工具栏及 AI 浮层统一细节；
用户文件染色、笔记本图标、显式颜色块、图片文字与危险/成功反馈保留原颜色语义。
共享顶栏只在笔记激活时跟随，其他工作区与全局设置保持独立。
普通背景使用纯色，沉浸层沿用浅色 `.48/.74/.80/.70`、深色 `.66/.78/.84/.76` 的
壳/侧栏/正文/工具栏透明度和原几何。交互颜色过渡 140ms，系统及笔记低动态取消，
不引入背景模糊、观察器、常驻动画或 RAF。

Sky 与 Apple 在根节点解析原外壳字体，再在图谱面板恢复；节点测量沿用原界面语言对应的
字体（中文沿用外壳栈，英文沿用原 `--font-interface-en`），图谱控件仍用原 `--font-ui`。
主题切换不将正文/UI 的新字体带入图谱，切语言也不会被固定成另一语言的字体栈。
