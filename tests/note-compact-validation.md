# 笔记公式、图片与画布留白修复验收

验收日期：2026-10-10。浏览器使用宿主 Playwright 与 Edge；桌面使用已有 Relatum 便携版的临时副本，覆盖当前前端资产，独立数据根和 WebView2 用户目录。全部笔记、图片和画布均为测试夹具，没有打开或改写真实用户笔记，正式发行包没有重新构建。

## 布局和输入

16px 正文字号下，简单公式的完整投影高度由调查时约 127px 降至约 34px。独立图片和画布各去掉上下两条额外边界行，合计约 53px；正文实际输入的空行保留。公式保留少量内边距，分数、根号、积分、上标没有纵向裁切，超宽公式在自身区域横向滚动，不撑宽窄窗编辑器。

投影边界与光标原子范围分别缓存。候选期间只映射受影响边界，沿用原 widget；原子范围负责媒体前后键盘导航，不修改 Markdown。边界规则参考 [CodeMirror Decoration 源码](https://github.com/codemirror/view/blob/main/src/decoration.ts)。

纯图片文档进入图片文字模式时，临时保留原输入边界行。实测完全消除可编辑行会阻断 Chromium 无 keydown 的原生输入；退出图片文字模式立即恢复紧凑布局，不增加文档空行或撤销步骤。普通图片显示和有正文的图片文档保持紧凑布局。

## Windows WebView2 与真实 Microsoft 拼音

使用 computer-use 的原生鼠标和按键，实际打开 Microsoft 拼音候选窗。CDP 仅读取真实文档、坐标和错误；本节没有用合成组合事件代替实际输入法。

| 实际操作 | 结果 |
| --- | --- |
| 点击公式后、图片前的“后文”，逐键输入 `h`、`a`、`n`，空格确认 | 拼音和候选窗在真实正文光标旁可见；候选停留期间磁盘正文不含拼音。确认后只有“后文含”写入原段落；一次 Ctrl+Z 恢复原文。 |
| 选中图片，右方向键进入图片后、画布前的“末文”，输入 `h` 后 Esc 取消 | 光标落在真实“末文”段首；候选可见，不被图片遮住，未提前保存；取消后文档不变。 |
| 滚动到画布后，点击“结尾”，输入 `h` 并空格确认 | 候选窗跟随当前正文坐标；确认值保存为“结尾和”，一次撤销恢复原文。 |
| 完成后检查 | 文档与磁盘均恢复原测试内容，没有额外空行；简单公式高度约 34px，图片已加载，画布无待绘制帧，页面无错误。 |
