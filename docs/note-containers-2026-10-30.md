# 笔记 Callout / 色块容器一致性

## 行为与数据

原有 17 类 Callout、别名、折叠和原生行编辑保留，颜色从 36 扩为 37。
标记同行是标题，只解析行内格式；例如 `> [!gray] # 123` 保留文字 `# 123`，
下一行的 `> # 123` 才生成正文一级标题。`white` 不区分大小写，无图标或默认标题；
`+/-` 可折叠且空标题显示 White。浅色白底，深色复用主题表面色（默认 #242424），
1px 主题细边框（默认浅色 #E5E5E5、深色 #444444），圆角随原色块主题，无阴影。
嵌套和富块首末共用静态祖先背景与边框，不在内部逐行画横线。

没有新 HTTP 接口、偏好或持久化格式，不重写已有笔记。普通画布未启用 noteBlocks
时保持原 Callout 协议；原 36 色配色不变。Callout 内标题仍不加入主文档大纲。

## 实现入口与接口

- `assets/markdown.js` 的 `parseNoteBlockHeader(text)` 返回原始类型身份、标题和折叠后缀；
  编辑器和笔记阅读/引导共用它，目录仍只读。
- `noteContainerSource(source, depth?)` 返回去前缀文本、逐行正文、原始前缀、正文在原文内的偏移及默认层级；
  `wrapNoteContainer(text, container)` 只给修改内容补回对应前缀，不改保存原文。
- `assets/note-live-editor.js` 扫描表格/图片/分隔线等时保留完整引用源码，另存解析视图；
  原始 from/to 仍用于历史、选区、复制、异步身份与保存。公式内的比较符号不当作额外结构剥除。
- `assets/note-table-editor.js` 的局部单元格/对齐快速更新接收含前缀原行；结构编辑按正文匹配
  复用未修改行的原格式，新行继承容器前缀。进入内部编辑前交接父光标，并重新核对组件身份，
  防止第一正文为表格的无标题容器在焦点变化时替换输入宿主。普通独立表格继续用原快速路径。
- 图片文字及媒体尺寸回写补回原前缀；代码复制去除结构前缀。已有 Mermaid、Quiz、公式和
  内嵌画布组件复用同一祖先背景，折叠后不挂载其隐藏实时投影。
- `note_canvas_reference.py` 与前端 canvasReferences 同时识别引用内 Markdown 画布嵌入；
  只调整引用范围，不放宽路径授权。引用代码、注释、前言保持保护，重命名和笔记移动保留引用前缀。
  围栏只由同一引用深度的结束标记闭合，代码示例中额外的 `>` 不提前解除保护；退出引用容器仍按原规则结束代码。
  `normalizePastedMath()` 使用同一深度约束，代码中的公式示例保持原字节，实际围栏后的正文公式继续规范化。
- 阅读排版只选展开的公式根，等待宿主完成显隐交接；展开折叠再次调度，异步任务核对阅读 epoch。
  无新增观察器或循环。引导共 70 个复制示例、46 个颜色块预览。
