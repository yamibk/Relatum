# 笔记 Mermaid / Pele 渲染与编辑预览（2026-10-23）

> 本文保留 2026-10-23 的 Pele 1.9.0 实现和性能基线。当前 Pele 1.12.0、单击选中/双击编辑、紧凑边界及高度图修复见 [2026-10-30 编辑层说明](note-mermaid-editing-2026-10-30.md)；下方旧基线数字不代表当前版本。

## 用户行为与范围

Launcher 的“笔记工作区”下增加默认勾选的“Mermaid 图表”。稳定 ID 为
`notes.mermaid`，与图谱、内嵌画布平级，不依赖主画布。版本 1 配置缺少此项
时采用默认值，关闭父项保留子项勾选。直接完整启动保持启用。

- 实时预览显示图表；点击或键盘激活后展开原围栏，并在结束围栏下方保留只读预览。
  首次立即调度，后续输入合并 120ms，仅提交最新源码。临时语法错误保留上次
  成功结果并轻提示，首次无结果只提示；同一块重新进入可恢复仍在缓存中的结果。
  预览点击不移动光标，不进入原子范围、撤销历史或正文保存。
- 已投影的 Mermaid 围栏不再产生代码行装饰，避免图上方出现空的代码底色条。
- 源码模式始终显示代码，不启动图表资源。
- 阅读模式适配正文宽度，保留 LR/TD 等方向；图表缩小时可缩放、平移、复位，
  普通滚轮继续滚动正文。滚出视口、隐藏和最小化只释放交互，保留未改变尺寸
  的缩放和平移；内容或布局变更才重新适配。控件支持中英文、键盘和触摸。
- 禁用后保留 Markdown，阅读显示普通代码与复制入口。
- 其他区域继续已有 Mermaid.js，本次开关只控制笔记。

Pele 支持 Mermaid 12.1.0 内置图表，使用自己的布局，不能要求与 Mermaid.js
像素一致。颜色来自主题 CSS 变量及作者显式样式；Mermaid 的 `themeVariables`
不等同于 Pele 主题。首版不排版节点内 LaTeX，也不提供外部图像、图表链接、
JavaScript 回调或外部图表插件。

## 源码与离线资源

`assets/vendor/pele/` 收录未经改写的 Pele 1.9.0 全量浏览器包、MIT 许可证和
来源/校验信息。`pele.global.js` 为 706,153 字节（约 0.67 MiB），当前旧 Mermaid
脚本为 3,572,657 字节（约 3.41 MiB）；两者都是未压缩文件大小。
运行与构建不需要 npm 或 CDN。

`assets/note-mermaid.js`、`assets/note-mermaid-worker.js`、专用 CSS 和 vendor
目录归 `notes.mermaid` 独占。
禁用时服务端拒绝访问；仅笔记会话不再加载旧 Mermaid 适配器。普通正文、
源码模式、未闭合/空围栏和隐藏编辑器预加载不触发 Pele。

原实时预览故障来自 widget 的 `toDOM()`：挂载前同步执行 `isCurrent()`，
因 `isConnected === false` 跳过，之后没有补发。新入口先在挂载后观察真实
可见性，再验证文档及块身份。引用/Callout 围栏保留包含引用前缀的原始源码
范围，另生成去前缀渲染源；不改磁盘正文。

共享 `MarkdownMini.renderResult(source,{mermaid:false})` 可关闭图表容器输出，
默认值保持既有行为，并传递至脚注递归。笔记渲染器不再依赖 `MermaidRenderer`。
适配器保留 `attach(root,{mode,isCurrent,onLayout,whenSettled?,editing?,historyKey?})`，
返回 `update(source,language)`（单图）、`suspend()`、`resume()`、`destroy()`。
`source` 是去围栏后的图表源码；`whenSettled` 用于编辑器的输入法交接。
`reserve(root,{mode})` 只恢复已知图高，不加载引擎或绘图。

## 性能、安全和生命周期

普通路径只在本地 Worker 加载完整 Pele，用 OffscreenCanvas 测字，按实际字体栈
加载已有 Open Sans 四种字形和 Noto Sans SC。解析模型留在同一 Worker 的私有
WeakMap 所在环境，主线程只接收 SVG 字符串和尺寸，不复制模型。
主线程缩放控制器独立于引擎；原生手势按帧合并，释放提交最终坐标，销毁不复位。
Worker 缺失、构造被阻止、加载失败或不支持字体测量时回退同版同步引擎。

主线程和 Worker 缓存各限 32 项及源码/SVG 的 8MiB UTF-16 计量，超大单项不驻留，
模型随条目淘汰。源码/几何未变直接复用；宽度或实际字体变化只重排，Gantt 本地
日期进入布局身份。不相关的 MathJax 字体加载、纯滚动和主题颜色不触发布局。
缓存 SVG 挂载时重新分配实例 ID 与 fragment/无障碍引用，不能共用可变 DOM。

SVG 清理在脱离文档的树中约每 4ms 协作让出，批间核对身份；候选、隐藏或替换
可以立即取消等待。先完成清理再挂载，使用节点交接避免完整复制。XML 解析和
最后插入/布局仍是同步步骤；不能据此承诺任意大图零长任务或固定帧率。
只在宿主及祖先上观察属性，不观察 body 子树；ResizeObserver 忽略纯高度通知。

编辑器保存最近实际高度，避免源码/图表组件交接先缩成空框再长大。阅读在恢复
scrollTop 前按内容和布局指纹预留图高、隐藏源码兜底，防止离屏图返回后变为不同
高度的代码而使可见正文跳动。数值提示独立限 2048 项/256KiB 计量，不保存正文或
SVG，也不启动 Worker。实际渲染或错误时释放预留，不锁滚动、不修改 CodeMirror。

源码上限为 65,536 个 JS 字符，沿用原编辑器的保护；不是 UTF-8 字节数。
Pele 输出限 4,000,000 字符，流程图和 agentflow 边限 5,000。实时预览超限
保持代码；阅读显示源码及限制说明。加载失败可重试，语法错误需编辑源码，
不会自动加载 Mermaid.js。

`links:false`、`images:false` 在渲染时固定设置。生成 SVG 在插入前再次移除
脚本、foreignObject、媒体、SVG 动画、事件属性、外部 href 和 CSS 资源引用。
错误及源码使用文本节点展示。内部 marker/gradient 的 fragment 引用保留。

切文档、模式、工作区，隐藏、原生最小化及 pagehide 取消任务，释放 Resize/
IntersectionObserver 和缩放行为；最后一个活动宿主退出即终止 Worker 并释放模型。
保留恢复所需监听、受预算约束的已清理 SVG 和数值高度。每块只排最新任务，消息
携带文档、块和版本，返回及挂载前核对身份。已开始的网络/字体下载不能抢占；
同步回退仍有原单图阻塞限制。候选期间不提交预览或强制测量，确认/取消后接续。
Markdown、撤销历史、偏好和笔记持久化格式均不变。

### 本轮实测：Worker 与同版同步 Pele

2026-10-23，同一 Edge、1280×900、低动态，使用笔记的真实正文/等宽字体栈，
三轮交替比较 `459b8a3` 和当前源码。
首显和完成取中位数；输入 P95 汇总全程 CDP 输入，最长任务取三轮最大值。
下表为毫秒，`0` 表示未观察到超过 50ms 的 Long Task，并非没有主线程工作。

| 场景 | 同步首显 / 完成 | 当前首显 / 完成 | 同步 / 当前输入 P95 | 同步 / 当前最长任务 |
| --- | ---: | ---: | ---: | ---: |
| 冷单图 | 50.7 / 68.8 | 114.8 / 114.8 | 5.2 / 4.4 | 0 / 0 |
| 相同内容再次打开 | 3.4 / 3.4 | 2.3 / 2.3 | 3.6 / 3.1 | 0 / 0 |
| 100 张重复图逐项浏览 | 11.4 / 740.9 | 6.9 / 741.5 | 2.1 / 1.9 | 0 / 0 |
| 100 张不同图逐项浏览 | 9.0 / 713.2 | 83.4 / 765.0 | 1.7 / 1.7 | 0 / 0 |
| 500 节点 / 3964 边 | 239.9 / 239.9 | 362.9 / 362.9 | 222.1 / 17.3 | 253 / 0 |

压力图的输入最大延迟从 238.5ms 降到 30.8ms；旧/新输入样本数为 24/111。
主线程 TaskDuration 中位数为 297.0/248.9ms，最终 SVG 布局约 19.8/22.1ms。
收益主要是把连续阻塞拆开，让输入能穿插执行。Worker/字体初始化、消息传递、
分批清理会增加等待；本次冷单图首显多约 64ms、完成多约 46ms，压力图完成
多约 123ms，不能宣称
所有图都更快出图。XML 解析、ID 收集/序列化和最终挂载仍同步，更大的 SVG
仍可能产生长任务；本次压力图结果不能外推为任意内容的帧率保证。

相同内容再次打开时，解析/布局次数从 1/1 变为 0/0；已缓存的 100 张重复图
从 100/104 变为 0/0（旧实现还受字体通知影响）。100 张不同图仍各解析和布局
100 次，缓存各遵守 32 项及
8MiB 计量，不以减少实际图表内容换取结果。Worker 测试的 64 组图与主线程
同字体、同宽度和同字号的 SVG 全文一致，没有观察到文字坐标差异。

| 场景，GC 后 JS 堆 MiB | 同步主线程 | 当前主线程 | 当前 Worker |
| --- | ---: | ---: | ---: |
| 冷单图 | 2.51 | 1.66 | 1.10 |
| 100 张不同图后 | 4.60 | 3.09 | 2.29 |
| 压力图后 | 5.18 | 5.52 | 4.09 |

后台计算需要独立引擎及模型，主线程还保留已清理的 SVG，压力场景的总 JS 堆
因此增加。8MiB 是各自源码/SVG 的缓存计量，不是进程或模型总内存上限；字体、
DOM、原生内存和 GPU 不在表内。最后宿主销毁后 Worker 为零，闲置没有新增 RAF；
模块的有界 SVG/数值高度缓存仍可保留供下次打开复用。原始三轮报告由测试写入
临时目录 `relatum-mermaid-pipeline-HKm77e/report.json`，复测可用上面的测试入口。

本轮已通过 Mermaid 浏览器、Worker 几何/缓存、真实隔离工作区及源码 WebView2
验收；同时回归 Markdown、实时编辑器、工作区契约、公式编辑预览、正文滚动、
视图状态、富块展示、17 种功能配置和关系图谱。源码 WebView2 使用当前脚本及
CSS，未构建新 EXE。阅读切到另一篇再返回的测试同时核对正文行的屏幕 Y 坐标，
避免仅检查 scrollTop 而漏掉图表高度变化造成的正文跳动。
