# 笔记搜索与菜单交互（2026-10-13）

## 行为和实现

- 搜索范围、排序和日历由浏览器原生弹层改为离线 DOM 控件，沿用纸面与中性墨色。两个日期入口保留，允许手输 YYYY-MM-DD、年月快速选择、今天/清除及键盘导航；再次点击日历按钮可收起。日期通过年月日回读校验，闰日有效，错误或颠倒范围不查询、不清空原结果；“截至”依然使用下一本地午夜作为排他上界。
- 搜索浮层由单一控制器互斥管理，挂到 body，打开时测量实际尺寸与视口边界，不受筛选区折叠裁切。浮层入场 160ms、退场 120ms、筛选区 180ms；单个入场帧及收尾任务可取消，旧 transitionend 核对当前状态及真实透明度。关闭立即 inert，隐藏、最小化、切页和销毁直接提交关闭。
- 文件夹及大型笔记本范围共用有限的原生平滑滚轮，连续目标累计、反向从当前位置接续。细触控板保持原生滚动、低动态立即切换；超过 200 项复用既有窗口列表。输入聚焦使用 preventScroll，筛选裁切容器使用 overflow:clip（旧浏览器保留 hidden 回退），避免展开过程中自动滚动使浮层误关闭。
- 所有笔记右键菜单打开后，工作区内下一次右键先收起，捕获并消费该事件。来自 iframe 的内嵌画布回调也遵守同一规则。菜单位置使用实际宽高；根菜单只过渡 opacity，避免 transform 改变固定定位子菜单的参照。正文选区、候选输入、保存与异步命令交接不变，旧剪贴板命令不能修改新菜单的 busy 状态。
- 普通菜单项的背景反馈限定为直接菜单按钮，颜色按钮保留自身填充，仅用外圈反馈。颜色面板打开时以自身 DOM 为 owner 发出 canvas:tooltip-block，共享提示层清除待显示/现有提示；整个面板关闭后释放。这样也阻止下方笔记本行路径提示覆盖面板。仅影响面板可见期间，不改提示偏好。

## 计算与生命周期

搜索结果宿主、标题、状态及分页入口保持稳定；按路径更新结果行，内容未变不替换高亮/标签 DOM，事件读取该行最新结果数据。大列表使用 reuseRows 和变高观察，不常驻缓存全部结果 DOM。相同条件重复提交跳过网络请求，主动刷新/重试及目录失效仍可重新读取；150ms 输入合并与候选确认规则不变。

文件夹候选复用宿主常驻路径索引的缓存；Map 身份、条目数量或类型改变时更新，替换索引释放旧缓存引用，正文/结果刷新不反复扁平化目录。范围选项内容未变时保持 DOM，过大范围只在打开时挂载窗口。没有 JS 滚动循环、常驻 will-change、模糊合成、第三方库、新配置或后台 API 变更。

后台刷新保留当前键盘候选，不让静止指针的布局重定向覆盖键盘选择；祖先滚动定位按帧合并，没有持续定位循环。正在操作的浮层跟随布局并始终限制在视口内，外部滚轮/焦点关闭。多页刷新先收集完整替换页，再一次提交，避免中间缩为第一页及重复重建窗口索引；分页读取期间的失效合并到完成后处理。游标失效时重读已加载页和本次请求页，恢复仍存在的焦点项，用户转到控件后不恢复旧滚动位置或抢焦点。无效日期期间的后台失效也不查询。离开取消输入合并的待查询并暂停结果列表；返回接续未提交条件。低动态开合立即提交样式，不保留入场 RAF。

搜索浮层通过宿主可选 onPopoverOpen 回调与工作区菜单互斥；closePopovers({instant}) 供切页与隐藏交接，getFolderPaths 为目录候选缓存入口，缺省仍可使用 getEntries。所有公开后端协议、持久化数据和功能裁剪规则沿用原行为。

## 验证入口与边界

使用既有 RELATUM_PLAYWRIGHT、RELATUM_PYTHON、RELATUM_EDGE_PATH 宿主运行：

- `node tests/note-ui-browser.js`：三个外壳；日历反复开关/反转、年月及闰日/无效范围/同日边界、键盘/外部关闭、菜单互斥、任意再次右键和子菜单、色块 hover/focus/press 保色与提示恢复、千项范围窗口化、后台候选保持、多页原子刷新及分页失效交接、焦点恢复、待查询取消与返回、结果/选项/目录快照复用、低动态/最小化/pagehide、闲置零 RAF。
- `node tests/note-search-browser.js`：三个外壳的真实查询、分页、结果返回、全文定位及 Chromium 原生候选输入。
- `node tests/note-folder-picker-browser.js`：千项目录的真实滚轮中间帧、连续/反向滚轮、窗口化、键盘/鼠标和迟到输入。
- `node tests/note-context-menu-browser.js`、`node tests/note-notebooks-browser.js`、`node tests/note-visibility-browser.js`：正文命令/选区/保存、笔记本事务及可见生命周期回归。

所有文件、偏好、服务与浏览器配置使用一次性数据根；截图可写入 RELATUM_ARTIFACT_DIR。当前验收为真实 Edge/Chromium，本轮不构建发布包；真实微软拼音候选窗及发布版 WebView2 仍需人工验收，不能把闲置 RAF 计数称为整机帧率或显存提升。
