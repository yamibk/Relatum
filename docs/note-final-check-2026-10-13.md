# 笔记工作区最终性能复查（2026-10-13）

复查最近的 SQLite 搜索、文件树局部更新、搜索弹层及菜单提交，并沿正文统计、大纲与图谱可见生命周期检查重复任务。本轮只修改自然名称排序规则的复用；其他路径已有窗口化、请求取消、按路径复用及隐藏释放，未找到足以继续改动的明确收益。

## 变更

`assets/note-workspace.js` 的文件树排序、笔记本排序和增量目录排序共用当前语言的 `Intl.Collator.compare`。原先每次 `localeCompare` 都传入数字排序与大小写/重音选项；现在只在语言改变时准备比较器。数字、大小写、重音、文件夹优先，以及路径平局回退或稳定平局的原规则保持一致。只缓存一个绑定比较器，不缓存目录内容或增加动画任务。

这减少大目录排序阶段的同步主线程阻塞。文件夹开合、侧栏、弹层的既有过渡与低动态行为沿用现状。
