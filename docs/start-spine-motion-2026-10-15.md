# 画布左侧书脊滑块：2026-10-15

这次只整理书脊动效控制、校准与生命周期。黑白实体仍表示真实当前页，彩色层仍表示悬停/键盘预览；纯黑/纯白、不透明实体、三种形状、独立滑块速度、现有缓动和光晕外观保留。

## 原因与实现

- 原悬停入口先测量目标放置提示气泡，再测导航与同一目标放置彩色层。实体同步还会在写入自身样式后再次调用彩色层测量；多个来源分别排队，突发输入重复执行。
- `syncActiveSpineOrb()` 现在只登记请求，所有来源合并到一个显示帧；该帧先读取导航与按 DOM 身份去重的目标边界，再统一写入。矩形仅在本帧存活；已提交的原始样式值用 WeakMap 记忆，避免 CSS 字符串规范化导致重复写入，也不保留已删除分组的 DOM。
- 相同目标/状态的同步不重启回位或呼吸。回位回调核对操作版本与当前目标，快速反向继续使用 CSS 从当前视觉位置插值，不增加逐帧 JavaScript 循环。
- 原 `animate:false` 只关闭彩色层过渡；真实隔离页面缩窗后实体仍在移动。现在临时过渡类覆盖全部三层，窗口、导航滚动、分组顺序变化及工作区重新显现时一起校准。普通分组翻页仍使用原位移与形变过渡。低动态不额外切换临时类。
- 彩色轮廓的 `border-width` 不再逐帧补间，1px/1.5px 的端点保持不变。其余视觉过渡和有限光晕保持原有规则。
- 隐藏、原生最小化、离开画布及 pagehide 取消排队更新、过渡恢复、回位与呼吸，并由局部暂停类停止三层 CSS 动画。恢复只重新测量当前目标；没有跨工作区迟到的测量或旧回调。

没有新增应用依赖、HTTP API、用户偏好或持久化字段；后端与用户数据不变。

## 验证方式

`tests/start-spine-motion-browser.js` 复用测试主机的 Playwright/Edge 与 Python，自建一次性 `RELATUM_DATA_ROOT`。真实首页验证页面入口、分组重建、导航滚动与画布/笔记往返；隔离宿主加载原书脊 DOM、完整 CSS 和从真实源码提取的控制逻辑，精确验证调度/读写与动效。

探针只在测试注入：70 次同任务悬停、20 次同帧当前页同步、同状态重复更新、进行中的反向、旧回位失效、方块/圆点/收藏星形、纯色不透明、resize 无过渡、Tab 导航、原生最小化、document.hidden、pagehide/pageshow 和运行中低动态切换。覆盖浅色 DPR 1、深色 DPR 2、浅色低动态 DPR 2 与 680px 窄窗。

`--compare` 交替装载 Git 基线和工作区资产，各三轮、两种主题/DPR。每个场景发送 24 次间隔 20ms 的悬停或切换，并计入 450ms 收尾；CDP 分别记录 Script、RecalcStyle、Layout、TaskDuration 及 Paint 事件。Paint 是浏览器的绘制记录阶段，不等于完整栅格化/GPU 或整机 CPU 开销。此调度与合成环境也不能换算成真实显示器帧率。
