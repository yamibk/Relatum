# 可配置笔记侧栏与笔记 AI

## 入口与设置

笔记设置包含“侧栏”“AI设置”“AI对话”，右栏入口仍叫“AI”。设置弹窗常规尺寸为
1200×820 CSS px，窗口不足时保留留白并缩小，窄窗沿用顶部分类导航。
原 AI 设置分类 ID 仍为 `ai`，AI对话使用 `ai-chat`，紧接其后并使用路径绘制的 AI 字母 SVG。
禁用笔记 AI 时同时隐藏这两个设置分类。侧栏默认顺序是笔记本、大纲、画布、引导、链接、AI，
可逐项隐藏、拖手柄、按上下按钮或在手柄上用方向键/Home/End 排序。
`canvas:noteSidebarPages:v1` 存完整 `order/hidden`，Launcher 关闭子功能只过滤显示，
移动可用项时保留不可用项的槽位。全部隐藏收起侧栏，左树的库设置齿轮仍可进入设置。
图谱页保留仅笔记本侧栏的规则，笔记本隐藏时同步裁剪图谱入口。

拖拽只改变设置行及页签 DOM 顺序，不清正文选区、不重建编辑器。固定列表承担指针捕获
和拖动期间的焦点，避免重排行触发捕获丢失；6px 阈值后启用浮影，其他行让位 180ms。
取消立即还原且不保存；完成保存一次。隐藏、最小化、失焦和退出分类清理捕获、浮影、
临时监听及动画，低动态直接落位。闲置无 RAF。

## AI 默认值与数据

笔记 AI 默认启用，功能标识 `notes.ai`，不依赖 `editor.ai` 或内嵌画布。
真实 AI 页、AI 设置或相关搜索按需加载其脚本/CSS，普通笔记不加载。

聊天侧栏在输入框正上方并排显示当前预设与思考强度下拉，长名称省略显示。
思考提供跟随模型默认、关、低、高、最高；默认对应 `thinking=auto`，关对应
`thinking=disabled`，低/高/最高对应 `thinking=enabled` 与 `effort=low/high/max`。
默认或关闭保留已保存的强度；改变思考参数保留当前对话和输入草稿，下一次请求生效。
两处入口双向同步，覆盖预设新增、改名、删除、重置及语言切换；重复选择当前预设不清空。
首次配置读取完成前禁用快捷控件，保存失败在输入区上方提示并保留待保存值，发送前等待保存。
聊天侧栏保留消息与底部输入区，不显示内部齿轮、历史行及空状态文案。
发送箭头左侧的同尺寸 `+` 开启新对话，取消当前请求、释放旧会话、清空消息和草稿并
聚焦输入，不常驻显示“已开启新对话”。工作区原有设置齿轮继续可用。
回到底部按钮按包含快捷栏、图片缩略图和提示的整个底部区域高度定位，避免遮挡控件。
右栏及设置大窗的消息输入框聚焦时保持原有细边框，不增加焦点描边或外扩阴影。

AI设置分类按当前对话预设、连接、生成参数和预设管理分组，使用细边框卡片、紧凑表单、
主次按钮及独立星芒 SVG。生成参数宽窗两列、窄窗单列；无预设隐藏空名称与提示词，
内置预设只读、可复制成自定义。当前对话预设与编辑预设相互独立。

全部下拉复用 `review-controls` 的自制触发器及列表，隐藏原 select 只保留表单值。
共享资源由 `notes.ai` 和 `canvas.review` 授权；首页静态标签仍归复习，独立笔记模式
首次 AI 入口才加载，不加载复习业务。设置弹层挂在原生 dialog 的专属绝对定位容器，
使用设置主题变量；聊天使用独立控制器，其弹层容器随活动宿主移入 dialog 或移回 body，
避免侧栏裁剪及工作区变换，打开菜单不关闭设置，设置重建不销毁聊天控件。
保留键盘、搜索、候选保护、有限动效及视口避让，靠近底部时
向上展开，低动态禁用过渡；搜索结果聚焦可见按钮。选项变化显式 refresh、禁用变化 sync。
设置切分类/搜索/关闭收起，重建释放旧设置控制器；右栏弹层与工作区菜单互斥，切侧栏、
关侧栏、离场、隐藏、最小化及 pagehide 收起并释放临时监听、观察器和帧任务。

## 设置中的 AI对话

AI对话填满设置右侧内容区，消息独立滚动，预设、思考强度、图片草稿和输入框固定在底部；
不显示分类恢复按钮，也不保留空白设置页脚。极矮窗口允许输入区内部滚动以保留控件入口。
分类搜索只匹配 AI对话名称及聊天相关关键词，不检索用户消息、图片文件名或回答正文。

`note-ai.js` 在侧栏 `.note-ai-dock` 中创建唯一的持久 `.note-ai` 视图，
`present({container,portal,isCurrent,whenSettled})` 将它与快捷弹层容器移到当前宿主。
消息、草稿、图片、预设、手动思考折叠和阅读位置保持同一份；不创建第二个聊天实例。
`holdPresentation()` 只暂停绘制并取消旧尺寸的公式排版、临时布局及未完成图片准备；
输入法候选结算后移动输入框，有限入场结束后按新尺寸恢复底部跟随或相对阅读锚点。
请求身份与显示挂载版本分别管理，交接期间继续累计 SSE 内容，恢复后合并显示，不重发请求。

正常关闭 AI对话弹窗后，`onClosed({reason})` 在原生 dialog 真正关闭后打开右栏 AI、
移回同一视图并继续生成；AI 侧栏页被用户隐藏或处于图谱布局时保持偏好、停止生成并保留对话。
从 AI对话切到 AI设置、其他分类或搜索结果时，停止生成并保留消息与草稿，返回不自动重发。
程序关闭、离开工作区、页面隐藏、最小化及 pagehide 不自动打开侧栏，仍停止并释放显示资源。
弹窗开合版本与挂载版本共同阻止快速关闭/重开后的旧回调移动新窗口里的聊天。
下拉先处理自己的 Escape，其他 Tab、Shift+Tab 和 Escape 交由原生设置弹窗的焦点循环与关闭处理。
后端接口、临时内存会话及所有图片限额保持不变。

| 字段 | 默认 |
|---|---|
| baseUrl | `https://api.deepseek.com` |
| model / apiKey | 空，用户填写 |
| stream | `true` |
| thinking / effort | `auto` / `high`；自动时均不发送，强度只在开启思考时发送 |
| temperature / topP | 1 / 1；显式思考时省略 temperature |
| maxTokens | `null`，不发送输出上限，采用模型默认 |
| timeout | 600 秒总超时；建立连接另限 30 秒 |

地址接受 HTTP/HTTPS 基础地址，也兼容末尾 `/chat/completions`，不会重复拼接路径。
温度 0–2、Top P 大于 0 至 1、输出上限自动或 1–393216 整数、总超时 1–3600 秒。
采样支持取决于模型，界面说明这一点，不靠模型名称猜测能力。测试连接只发送极短 user
消息，不写会话；默认聊天没有隐藏 system 提示词。

浅色主题下，聊天输入容器使用近白色表面；深色主题保留墨灰表面。

`data/note-ai.json` version 1 保存连接、生成参数和自定义预设，沿用原子 JSON 写入。
API Key 按明文保存在该本机 JSON 文件中，不写浏览器持久偏好、聊天记录或日志。普通配置
GET 只返回 `hasKey/keyHint`；短 Key 完全掩码。聚焦 Key 输入框时才通过受功能开关保护的
本机 `reveal-key` 路由取回完整值并显示，失焦清空输入并恢复掩码提示，移除重复的显示按钮。
只查看不保存；输入草稿优先于异步读取，失焦、清除、重建或关闭使旧读取失效，迟到结果
不能覆盖新输入或恢复已清除的值。其他配置改变合并 350ms 保存，
失败保留待保存值并显示状态，无效字段不覆盖已保存值。
AI 分类重置和全部笔记重置保留模型、Key、预设与当前临时对话。

聊天暂时下线持久历史。每个 Store 按需建立单个 SQLite `:memory:` 连接，配合 RLock、
`check_same_thread=False` 和 `temp_store=MEMORY` 供请求线程短事务交接，复用原有表结构、
外键级联和请求身份保护。正文、思考、状态、用量及提示词快照只存在进程内；不写入
浏览器持久存储，也不读取、写入或迁移旧 `data/note-ai.sqlite3` 及 WAL/SHM。
旧文件原样保留，不能当缓存删除。`close()` 幂等取消请求、关闭连接；关闭后的迟到保存
不能重新打开数据库，源码与桌面退出统一调用 `app.close_note_ai_stores()`。

不导入、迁移或修改画布 AI 的 `data/ai.json`。所有新增用户数据沿用 data 目录忽略规则。

## 预设和会话

内置 `none / dictionary / deepseek`：无预设没有 system；查词原样保留用户 HTML 中的
词频、释义、例句、搭配与辨析提示词；Deepseek 为简体中文通用助手。
内置只读，可复制后编辑；最多 100 个自定义预设，每份名称最多 80 字、提示词最多 65536 字。
预设仅包含提示词，共用调用参数。在设置或右栏切换到不同的当前对话预设开始新对话，空白对话首次
发送才登记到内存。已开始的对话保留当时的提示词快照；修改或删除预设不改变它。
启动默认无预设，只在本次运行记住所选项，不增加配置字段；重启及页面重载不恢复对话。

侧栏页签/工作区切换和最小化保留当前对话及草稿；正在生成的请求仍取消并保留部分回答。
右栏与设置 AI对话之间的显示交接及正常关闭后返回右栏继续当前请求，不属于停止操作。
`+` 或切换预设后清理旧对话，清理等待旧客户端请求收尾；取消早于登记仍生效，迟到输出
不进入新对话。连续点击不登记空会话，页面离开用 keepalive 做尽力取消和清理。

聊天只发送输入、粘贴内容和主动附加的图片。每条用户输入最多 262144 字符；单次上下文只选最近 19 个
完整轮次及当前输入，额外保留可选 system，最多 40 条消息；文字部分超过 8MiB 时明确提示新建对话。
失败/中断轮次不污染新上下文，当前对话的完整消息保留，最后失败轮次可重试替换。
回复最多接收约 2Mi 字符（UTF-8 不超过 8MiB），截断结束原因保留在内存并明确显示。

首次连接配置读取完成前禁用输入；前端不再查询或恢复历史。复制使用原文，
不改笔记或调用画布动作。Enter 发送、Shift+Enter 换行，原生候选不发送。

## 图片输入

输入框底部增加细线、圆角的回形针 SVG，与 `+`、发送按钮同尺寸。支持选择多张图片、
粘贴截图和拖入；普通文字粘贴保留原生行为，图文剪贴板同时保留可粘贴的文字。
图片在输入框内、文字上方显示文件名和紧凑缩略图，可逐张移除；已发送图片归属到对应
用户消息，也可不输入文字直接发送。准备图片期间禁止发送，生成回答时可编辑下一条草稿。

仅支持 PNG、JPEG、GIF、WebP，每条最多 4 张、原图合计最多 4 MiB；单边最多 8192 像素、
总像素最多 1600 万。超限明确提示，不自动压缩或改写原图。前端读取最多 1 MiB 文件头，
在解码前检查真实格式及尺寸，再逐张生成最长边 160px 的本地 PNG 缩略图；后端复用
`notes_library.py` 的纯文件头识别、尺寸读取，独立检查 MIME、Base64、大小和像素边界。
无法安全识别尺寸时拒绝，不按文件名或声明 MIME 放行，不接受 SVG、远程 URL 或本地路径。

选择图片只在本机处理，点击发送后才把原始图片编码为 data URL，经原有聊天接口转为
user 的文字和 `image_url` 内容块。纯文字协议不变；不调用正文图片上传接口，不写入笔记
及素材目录，不接远端 Files API，不新增 SDK、npm、偏好或持久化字段，不更改模型。
服务商拒绝带图请求的 400/422 统一提示检查模型/接口图片能力及生成参数，隐藏上游错误详情。

原图保存到同一个 SQLite `:memory:` 的附件表，随消息外键级联删除；后续完整轮次继续带图，
重试通过原请求复用原图，不接受替换附件。HTTP 入口在读取正文及大包串行锁前拒绝超过
8 MiB 的聊天请求；文字上下文仍限 8 MiB，带图请求总上下文限 24 MiB，不静默移除图片。
会话累计原图限 32 MiB、整个 Store 限 64 MiB，失败保留草稿并提示新建对话或释放旧会话。

文件读取、缩略图及发送快照核对当前会话和操作身份；失败恢复不覆盖新输入的文字/图片，
没有收到登记事件的请求重试时重新发送原快照。新对话、切预设和退出释放旧附件；切侧栏、
隐藏及原生最小化保留已完成的草稿，取消尚未完成的读取和发送准备，释放缩略图 URL、
位图及画布资源，恢复只重建本地显示。未变化的缩略图 DOM 在流式回答中复用，无闲置 RAF。

## 消息阅读与流式排版

用户消息靠右使用紧凑文字气泡及图片缩略图，回答占满当前聊天宿主的可用宽度，不显示重复角色名。
回答和思考使用共享安全 Markdown；标题、列表、引用、表格、代码和公式按聊天字号排版，
宽公式、表格及代码只在各自区域横向滚动，不改变侧栏宽度或正文预留。
对话、输入框及代码/表格/公式滚动条与笔记设置统一为 6px 细圆角外观，透明轨道、
无两端三角按钮，颜色随主题变化；只用宿主范围内的 CSS，保留原生拖动和滚轮。
复制按钮使用本地 SVG，成功后短暂显示勾选；上下文轮数、token 及整轮耗时集中在可聚焦的
回答详情中，停止、失败和截断仍直接显示，最后失败轮次保留重试。
输入框自动增高至 240px/28vh 上限后内部滚动，回形针、`+` 与发送/停止按钮及 SVG 同尺寸居中；
移除快捷键小字和原生拖拽角，保留原快捷键和候选保护。

流式按约 120ms 合并，根据解析耗时最多放宽至 600ms；终态立即提交。
每个表面的完整源码经 `MarkdownMini.renderResult` 转为安全片段，以渲染前签名比较顶层块，
未变化的块和 MathJax DOM 原位复用。未闭合公式的尾部保持原文，闭合后再排版，
支持 `$…$`、`$$…$$`、`\(...\)`、`\[...\]`，代码中的分隔符保持代码。
图片在脱离文档的模板中转为文字；不初始化笔记附件、双链或画布能力，Mermaid 只展示代码。

`RelatumNoteLiveEditor.typesetMath(host,isCurrent)` 是内部复用入口，共用现有离线 MathJax
加载器和公式预览的串行槽，不增加 HTTP 接口、配置字段或存储。只在真实公式触发，
在局部隐藏容器排版后交接，检查可见生命周期、消息及块身份；更新和移除清理局部记录，
迟到结果再次核对并清理。没有全页公式观察器或 Mermaid 运行时。

思考标题使用按钮、旋转 `>` 与细竖线，思考时默认展开，收到回答正文后收起；
每条消息的手动选择优先，支持 Enter/Space 和 aria-expanded/controls。思考用时是客户端
观察到该阶段的时长，区别于回答详情的整轮耗时。折叠约 180ms，可从当前高度反转，
关闭立即 inert；低动态、隐藏及最小化提交最终状态，不保留动画任务。

靠近底部时跟随输出；上滚后保留可见块锚点，显示回到底部按钮，点击或发送恢复跟随。
公式交接、输入区及折叠高度改变继续维护锚点；观察器仅在可见时连接，布局按帧合并。
新对话释放旧块，切页/隐藏/最小化取消待排版及绘制任务、折叠、复制计时与临时监听，
保留当前消息和草稿，恢复不重发。闲置不调度 RAF，无新增持久化偏好。

## 内部接口与生命周期

所有接口位于 `/api/note-ai/`，路由入口显式检查 `notes.ai`，在访问任何文件或出站前
完成检查，避免父级笔记 API 的宽前缀放行。

| 接口 | 用途 |
|---|---|
| GET/POST `config` | 安全配置视图、合并修改、`{reset:true}` |
| POST `reveal-key` | 仅在 Key 输入框聚焦时读取本机完整 Key，受 `notes.ai` 保护 |
| GET `sessions?offset=…` | 仅进程内会话的兼容接口，前端不再调用 |
| GET `messages?id=…&before=…` | 仅进程内消息的兼容接口，前端不再调用 |
| POST `session` | 保留 `select / rename / delete` 协议；当前前端只用 delete 释放旧对话 |
| POST `chat` | `sessionId/requestId/text/presetId/newSession/retryOf?/images?`；`images:[{name,dataUrl}]`，返回 SSE |
| POST `cancel` | 按 requestId 幂等取消，兼容取消早于请求登记 |
| POST `test` | 可取消的短连接测试，不保存对话 |

SSE 事件为 `meta/reasoning/delta/usage/error/done`，meta 附带本轮是否包含图片的 `hasImages`。
兼容的 messages 查询仅返回图片元数据，不返回原图。首个 meta 前验证配置、身份和图片预算，
先登记用户消息到内存再出站；部分回复每约 400ms 合并更新内存，终态立即提交。
同一会话同时只允许一个请求，唯一 requestId 防重复，删除后的 UPDATE 不会重新创建行。
错误只返回稳定代码，保留 401/402/429/5xx 区分，不转发可能含凭据的上游错误详情。

urllib 使用本机标准库 HTTP/HTTPS 传输，响应头及正文经非阻塞读取与 100ms 有界 select
检查取消；代理 CONNECT 的响应头也保留协作取消，但其读取器切换过套接字模式，结束后
必须恢复连接超时模式，再交给 TLS 自动握手，否则本机代理环境会在出站前抛出
`do_handshake_on_connect should not be specified for non-blocking sockets`。
关闭上游连接并取消总超时计时器。拒绝自动重定向。网络等待不持有全局数据锁。
普通失焦保留聊天；切换预设/侧栏页、关侧栏、离场、隐藏、原生最小化和 pagehide
停止当前请求、保留部分回答及中断状态，取消待渲染帧。恢复只显示原会话，不自动重发。
