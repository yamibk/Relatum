# 起步页性能收尾检查

本轮修改 `assets/notes.js` 的速记墙渲染与相机时间步长，以及 `assets/tree-page.js` / `assets/study-route.js` 的边缘拖动时间步长。画布编辑器、全局视觉、数据格式和实际用户数据未改动。

## 确认的问题与修改

- 原先每次速记墙平移/缩放都会删除并重建所有连线和箭头，且在线条写入之间重复读取两端便签的矩形，造成强制布局。现在按 ID 复用 SVG；真实几何变化时先批量读取，每张被引用的便签只测量一次，再统一写入。相机帧只投影缓存的世界坐标，线宽、箭头和阴影保留原来的屏幕尺寸。
- 便签编辑、叠摞展开/收回和新建动画会改变几何，不能单纯缓存后不再更新。只对被引用的便签观察尺寸，并在有限位移动画期间跟随端点；动画结束、取消、离页、切到笔记/生涯或页面隐藏时停止。观察器和几何缓存不持久化。
- 原先缩放和方向键平移把每帧间隔下限设为 0.35 个 60Hz 帧，240Hz 的真实间隔只有 0.25 帧，因而会加快运动。现在按真实间隔推进，并让便签相机变换与连线投影使用同一精度。

## 测量结果

基线：`11cc84e9982e74ce34a6ae44275a4c782e96c688`。本机无头 Edge 152.0.4191.66，1440×900、DPR 1、CPU 不降速；96 张便签、192 条连线、12 支箭头，每轮约 2.4 秒连续缩放，前后各三个独立浏览器上下文，表内取中位数。

| 每轮指标 | 原版 | 修改后 |
| --- | ---: | ---: |
| 新增 SVG 元素 | 29,376 | 0 |
| 删除 SVG 元素 | 29,376 | 0 |
| 便签/台面矩形读取 | 56,327 | 23 |
| 布局计算次数 | 28,656 | 145 |
| 布局总耗时 | 141ms | 27ms |
| 脚本总耗时 | 344ms | 74ms |
| 主线程任务总耗时 | 880ms | 418ms |
| RAF 间隔 P95 | 16.9ms | 16.9ms |

修改后的矩形读取来自滚轮输入时获取锚点；相机动画帧不再测量便签。脚本耗时约减少 79%，布局耗时约减少 81%。这些结果表明渲染负担下降，不表示实际帧率提升相同比例；无头浏览器的 RAF 采样约为 60Hz，不能代替用户 240Hz 屏幕上的桌面 WebView2 呈现测量。

## 树状页与学习目标树补查

两页的整枝拖动，以及树状页右键拖拽视觉关系线，原先都按每帧固定距离自动平移视野。使用实际源码函数与虚拟时钟，把指针固定在 1440×900 视口的右缘内 1px，运行一秒：

| 刷新率 | 原版移动距离 | 修改后移动距离 |
| --- | ---: | ---: |
| 60Hz | 594px | 594px |
| 120Hz | 1,188px | 594px |
| 144Hz | 1,425.6px | 594px |
| 240Hz | 2,376px | 594px |

现在依据 RAF 时间戳积分，保留原 60Hz 的每秒速度，在高刷新率下使用更细的位移。中央区域停止帧循环，重新到达边缘时重新计时；长帧最多计入 40ms，避免恢复时突然跳动。这是可控性修正，不是宣称把页面帧率提升四倍。

`tests/tree-page-motion-regression.js` 运行三个真实手势函数链，覆盖四种刷新率、左右/垂直边缘、中央停帧、长时间停顿后重入和迟到的时间戳。模型、结构落槽、持久化与动画样式不变。

浏览器另使用一次性数据根，为两页各创建两棵包含阶段和任务的树。浅色、深色、820×760 窄窗、低动态四种环境下共 12 组边缘拖动通过，整枝跟手误差低于 0.001px；回到中央及取消后无遗留 RAF。正常松手后的整枝重挂、右键视觉线保存、数字栏切树、树状页滚轮切树与视口滚轮缩放也通过，并确认过渡完成后停止帧任务。截图未见本次修改导致的布局或外观变化；浏览器验证仍不等同于物理 240Hz 呈现测量。

## 验证范围

- 真实浏览器验证初始/缩放/方向键平移端点、SVG 身份复用、叠摞动画中间态与收尾、实时正文增高、字号变化、拖动、新建带连线便签、删除/撤销/重做、搜索、箭头创建与划线删除、保存格式、窄窗适应和低动态。
- 静置检查覆盖速记、独立树状页、学习、专注、日历、复习和活跃页；有限入场结束后的采样未发现页面 RAF 空跑。除速记夹具外其余使用隔离空数据，此项不代表高密度业务数据的全面压力测试。
- 顶层笔记/生涯工作区切换与返回另做速记墙观察器清理及端点恢复回归。
- 虚拟 60/120/144/240Hz 时钟验证缩放缓动及方向键一秒位移一致。相关 JS 语法、速记相机、便签色库、起步页默认视图与页面计时契约通过。
- 补查的全部 253 项 Python unittest 通过；43 项 Node 契约中 39 项通过，新增树状页时间步长回归通过。四项旧失败在未修改的 HEAD 源码中同样复现：`ai-panel-v2-contract.js` 的控制坞断言、`canvas-taskbook-contract.js` 的旧文案断言、`tools-neutral-ui-contract.js` 的样式范围断言，以及 `study-progress-contract.js` 的旧函数签名断言。本次未修改这些断言或对应实现。
- 测试服务自建一次性 `RELATUM_DATA_ROOT`，速记读写使用确定性替身。结束后关闭测试服务和浏览器，不连接真实用户数据。

## 复现

使用测试主机已有 Playwright 和 Edge；不为应用引入依赖或构建链。

```powershell
$env:RELATUM_PLAYWRIGHT = '<已有 Playwright 模块的绝对路径>'
$env:RELATUM_PYTHON = '<已安装 Python 可执行文件的绝对路径>'
node tests/notes-camera-contract.js
node tests/tree-page-motion-regression.js
node tests/notes-browser-performance.js '<修改后结果.json>' regression

$env:RELATUM_NOTES_BASELINE = '1'
$env:RELATUM_NOTES_BASE_REF = '11cc84e9982e74ce34a6ae44275a4c782e96c688'
node tests/notes-browser-performance.js '<原版结果.json>'
```

`RELATUM_NOTES_ROUNDS` 默认 3，`RELATUM_NOTES_COUNT` 默认 96；`RELATUM_EDGE_PATH` 可指定已安装的 Edge。基线素材通过 `git show` 读取，工作目录不回退。
