# 笔记图文块

## 写法与操作

```markdown
> [!media]
> ![图片说明|240](示意图.png)
>
> **说明标题**
> 第一行说明。
> 按回车后仍在右栏。
>
> 新的段落。
```

首张图片支持现有本地 Markdown/wiki 图片及图片文字元数据，不增加远程图片能力。图片之后第一个空引用行作为结构分隔，空说明区有效。每行保留 `>`；离开对应引用层即结束。标记不带标题或折叠后缀，大小写不敏感。普通画布未启用笔记语法时不识别此布局。

图片和文字顶部对齐，文字始终在右栏；自动折行不写入回车。单回车显示换行，空行分段。支持标题、段落、列表、强调、高亮、普通安全链接、双链、行内代码和行内公式。其他图片、表格、块公式、代码围栏及嵌套富块显示源码，不启动相应组件；外层仍可放在原 Callout 中。

外框透明，1px 主题灰边、12px 圆角、12px 内边距、16px 图文间距。图片没有显式宽度时默认不超过 240px 和原图宽度；原有显式尺寸保留。右栏以 240px 为最低可用空间，放不下时自动上图下文。用户拖动图片时，右栏立即折行和撑高；释放只提交一次尺寸，Esc/失焦/取消恢复原尺寸。没有新增常驻按钮、外框阴影或动画。

直接点击右侧编辑。Ctrl+Enter 到块后正文，Ctrl+Shift+Enter 到块前正文，Esc 结束右侧编辑并选中整块。右栏首尾的退格/删除不会误删图片。删除明确选中的左图会保留说明文字；明确选中整块后才删除全部。整块复制保留真实引用 Markdown，右侧选择复制对应正文源码。

独立图片右键“转换为图文块”，保留原图片路径、尺寸及图片文字并立即聚焦空说明；转换可一次撤销。“笔记设置 → 引导 → Media”提供示意、源码与复制，分类及面板标题在中英文界面均为 Media。示例图使用本地静态 SVG，不读取用户文件或联网。

## 实现与数据

- `assets/markdown.js` 暴露 `parseMediaBlock`、`mediaLiteralLines`、`renderMediaBody`、`renderMediaBlock`。解析保存原始引用前缀和图片/正文偏移；阅读与引导共用受限安全正文渲染。代码和注释中的标记不生成图文块。
- `assets/note-media.js/css` 管布局及轻量正文输入视图。`note-live-editor.js` 将图文登记为独立富块，复用原图片创建、图片文字、尺寸序列化、行内投影、格式操作、链接补全、测量与有界高度提示。
- 父 Markdown 是唯一正文及历史。进入右栏时创建输入视图，退出时释放；文档变化按块身份更新，输入中不重建宿主。输入位置映射回父源码，新行补回引用前缀，未改行保留原格式。
- 中文候选只存在于子输入视图；确认后才提交父文档。保存/切文档/切模式等待结算，候选期间点击外部正文时映射最终落点。连续输入合并历史，粘贴及候选确认保持独立撤销边界。
- 图片沿用现有授权、失败提示、资源管理器和回收站入口。`imageTextRenderedLines()` 包含图文左图，图片文字清理保留这些活动数据。附件清理和双链索引直接识别正常引用 Markdown，无后端协议修改。
- 延续 256KiB 富块、64KiB 单行上限。超过限制时完整编辑仍回写父正文，取消富块投影，避免丢失输入。
- 图文范围整体保护，外层表格、图片和块公式补充扫描不会再次挂载右侧的源码示例。阅读定位直接使用原始行偏移，文档前言及标题占位符不改变位置；段落中间的块公式也保持源码，行内公式环境和代码中的公式标记保留各自语义。
- 每个富块保存已解析模型及正文行偏移；未变源码、光标移动和图片范围解析复用该模型，正文引用位置双向映射按行二分查找。子编辑器仅按文档身份更新受限语法行集合，挂载期间的祖先装饰按容器身份复用，多个尺寸失效在同一微任务合并。没有新增全局正文缓存。
- 远处尚未挂载的图文支持搜索定位；挂载完成后进入右栏并选择真实命中文字，正文、文档或选区变化会作废待定位请求。
- 图文公式共用已有可见生命周期：隐藏或最小化时不启动排版，恢复后接续；迟到结果核对预览版本、文档、块和可见身份，避免更新新输入宿主。不增加生命周期监听。
- 样式首次有效图文渲染加载。测量使用原入口及挂载期间的尺寸观察，销毁断开观察、释放公式/图片和候选收尾。没有新 HTTP 接口、配置键、依赖、数据文件或正文迁移。引导仅扩展既有主题偏好枚举为 `media`。
- 两种首页外壳通过共享笔记运行时加载，独立 Markdown 文件窗口加载相同模块。普通画布语法保持原状。

主机已有 Playwright/Edge/Python，使用 `RELATUM_PLAYWRIGHT`、`RELATUM_EDGE_PATH`、`RELATUM_PYTHON`。Python 测试导入前另设置一次性 `RELATUM_DATA_ROOT`。所有笔记、素材、服务和截图在专用临时目录，测试服务结束后关闭；未接触生产笔记或配置。

通过：

- `node tests/note-media-regression.js`：普通/wiki 图片、尺寸、CRLF、空说明、无效标记、代码/注释保护、换行、安全转义、双链、行内公式及受限富块。
- `node tests/note-media-browser.js`：四主题 × 深浅 × 宽窄 16 组；原图片手柄缩放/取消及撤销；直接定位、Enter、列表续项、连续输入和候选确认的撤销/重做；长文自动折行、边界删除、整块复制/删除、图片文字保留、源码往返、超限回退；真实离线 MathJax、迟到结果清理、嵌套 Callout、中英文引导和独立 Markdown 窗口 CSS。
- `node tests/note-media-workspace-browser.js`：真实工作区右键转换、正文输入及原生合成候选、鼠标/键盘右键菜单复制粘贴、真实落盘、源码/阅读往返、连续输入后切笔记、外部检查、缩放保存和页面重开。
- `python -B -m unittest tests.test_note_media_blocks tests.test_note_index tests.test_note_media_trash tests.test_note_reveal`：50 项通过，包含真实字节保存、UTF-16 搜索偏移、双链、附件清理保护及回收图片后说明保留。
- 既有 Markdown、Markdown notebook、实时编辑器、Cards、工作区契约和有超时子进程的模糊语料回归通过；原容器浏览器 16 组、图片兼容、图片文字工作区及 notes/library 资源权限回归通过。
