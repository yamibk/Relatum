# 画布导航与切页控制：2026-10-17

当前点击和滚轮的内容合并窗口已从 60ms 缩短为 40ms，减少 20ms 主动等待；约 50ms 间隔的连续输入可能因此激活更多中间页。整页导航收到输入即开始旧页淡出，日历退场默认时长从 104ms 再缩短为 78ms，其他整页保留原活跃页的 169ms 柔和节奏；选中方块↔圆点加入同步轮廓形变。滚轮到首尾即停，分组圆点按身份复用，滑块移动时长和普通分组之间较快的局部交接保留。此前仅对 104ms 日历版本做过下述专项隔离诊断，本次 78ms 调整按用户要求未运行后续测试、性能验证或重新打包，现有 EXE 保持不变，不宣称效果或性能已验证。除单独注明的 104ms 诊断外，既有完整验收、性能数值、截图及记录哈希均来自此前的 **60ms、无连续形变、无提前淡出版本**，不作为当前版本已验证的证据。

## 实现边界

本次重构左侧导航和页面交接，不改变页面业务、HTTP API、用户数据或偏好格式。新增 `assets/start-navigation.js` 和 `assets/start-spine.js`，在 `start.js` 之前加载，并沿用画布首页功能的 OR 裁剪规则。打包资产仍由既有清单规则收集。

`start-navigation.js` 只有当前路由、待选路由和操作版本。普通导航共用 40ms 安静期，原有立即执行入口保留；导航目标立即反馈，期间被跳过的页面不执行激活。相对滚轮从待选页继续，页序只包含实际启用的特殊页及画布库页，关闭画布库后不保留虚拟圆点页。到首尾时直接忽略越界目标，不循环、不发同页请求、不触发重复点击动作，也不重新启动待选页的计时或旧页淡出；反向滚轮立即向相邻页接续。原滚轮热区、阈值、内容滚动和侧栏溢出滚动保留。实际提交后才改变 `.active`、`aria-current`、页面生命周期和分组偏好，`.is-target` 表示即时目标。

准备、模块就绪、分组退出和附带操作通过同一 AbortSignal 及版本交接。候选输入期间不切换编辑 DOM；准备中开始候选会取消旧准备、恢复现场，结束后重新准备最新目标。已开始的保存继续由原模块完成。普通分组的无身份双层定时器和强制 reflow 已移除；退场/入场句柄可取消。已提交的分组入场归宿主所有，新请求在安静期内不取消它；切到特殊页时内层入场或恢复自然完成，外层负责退场，避免取消内层时跳到最终样式。

整页切换的旧根层在导航输入同任务启动 WAAPI 淡出，取真实透明度并保持当前显示位置。复习、活跃、速记、树状、学习、专注及最近/收藏/分组离开画布库时，继续使用翻页速度 ×0.65、限制 120–220ms，默认 169ms；仅旧页为日历时改用翻页速度 ×0.3、限制 60–120ms，默认 78ms，相比原 104ms 缩短 25%。两者仍用 `cubic-bezier(.4,0,.2,1)`，只缩短日历退场时长，不改变其他页面进入日历时的退场、日历入场或内部动画。连续经过多个目标只复用这次淡出，不提前初始化它们；新内容仍按 40ms 合并窗口和模块准备提交。提交后不重新播放旧页淡出；若已淡完，提交时立即隐藏，否则在淡完时移除其退场层并释放冻结资源，不等待最长 480ms 等统一收尾计时。活跃页沿用星图最后一帧和现有暂停/释放交接，不重写业务渲染。此前用于提交时重播中断根层退场的另一套 WAAPI 句柄已移除。顶层工作区及页面内部模式动画不受本次调整影响。

日历标题残留的专项诊断使用 `200975b` 的 104ms 版本、已有 EXE 和 WebView2 155.0.4283.60，数据及浏览器配置隔离。页面按钮调用与合成滚轮各采样一次 DOM/动画时间线：日历在约 94–99ms 的采样中透明度已约为 0.015，在约 120–135ms 时 `visibility:hidden`；旧 CSS 退场随之取消，没有等到约 525ms 的统一清理。两次空数据采样未复现异常长残留，不是物理屏幕逐帧或完整用户数据验收。原始诊断保留在临时目录 `relatum-calendar-exit-diagnosis-p5eR45/report.json`。本次根据标题短暂残留的观感再次缩短时长，不作为已确认 bug 的修复，也未对 78ms 版本重新采样。

取消导航或准备失败时，用 120ms 从当前画面恢复原根层，编辑 DOM 保持原位；恢复和淡出的完成回调均核对当前会话身份。输入法候选开始时立即恢复，结束后再启动最新目标的淡出；隐藏、离场、原生最小化及低动态立即结清相应效果。最近/收藏/普通分组之间沿用原局部交接：40ms 安静期后，以 `max(90ms, 翻页速度×40%)`、默认 104ms 淡出并沿原方向移动，结束后替换复用容器的内容；保留原缓动、入场及取消逻辑，不叠加整页淡出或增加这一流程的主动等待。导航浏览器套已有同任务起播、连续目标不重播、返回恢复、迟到提交立即收尾及准备失败恢复用例，后续按用户要求未运行。

页面继续使用原 activate/deactivate/finalizeExitMotion 接口，先登记退场再停止交互，最后释放资源。重复点击日/学/专的模式切换、树状/速记复位及长按归档保留。专注日期跳转在模块就绪和读取会话后都核对身份，迟到响应不能滚动或打开旧会话编辑器。后台目录刷新不重复激活当前特殊页；当前组删除后的回退不覆盖更新的意图，隐藏期间不排微任务重试。

## 滑块绘制

载体固定为 38×38，实体表面及反色裁剪也使用固定布局尺寸。选中方块↔圆点使用相同 `clip-path`，在 `inset(2px round 13px)` 与 `inset(13px round 6px)` 间连续补间，最终可见尺寸仍为 34px 和 12px；星形保持原轮廓及直接切换行为。裁剪与位置沿用同一滑块速度和缓动，快速反向由 CSS 从当前可见轮廓接续。彩色悬停层保留原行为，纯黑/纯白实体始终不透明。

方块与圆点的阴影各使用一个固定图层，切换时只交叉补间透明度；避免表面裁剪切掉阴影，也不连续改变阴影模糊半径。有限的呼吸与搜索反馈继续只改变独立伪元素透明度。立即校准、低动态和隐藏清理同时覆盖表面形变、字形裁剪及阴影，没有新增 JS 动画循环或常驻合成提示。形变会增加局部裁剪、绘制或合成工作，具体成本未经实测，不能将此前零逐帧布局或帧间隔结果当作本次形变已验证的性能结论。

独立滑块套已同步固定布局与最终可见尺寸断言，补充深浅色下默认 414ms/800ms 方圆中间态、快速反向、实体/反色裁剪一致、缩窗/最小化/低动态收尾，并保留包含两个方向的逐帧 LayoutCount 检查。这些新增和调整的回归均按用户要求未运行。

七个特殊入口保留正常主题字形，滑块内有一条反色字形轨道。载体正向位移和轨道反向位移使用同次写入、相同速度和缓动，字形屏幕坐标抵消，只有裁剪窗口随实体走。图标颜色不再由 `.active` 状态追赶移动的背景，也不使用 blend-mode。副本仅有 `spine-copy-*` 展示类，没有业务属性、id、按钮、监听器或无障碍入口；普通分组/收藏的纯实体选中外观保留。

窗口/导航滚动、局部尺寸、分组、字体/语言、主题及可见性变化使布局快照失效；集中测量后统一写入。普通输入不测边界，相同目标不重复写属性。隐藏、离开工作区、最小化及 pagehide 取消待提交导航、准备监听和动效；恢复校准当前页，不复活旧请求。静止后无导航 RAF。

`renderDots()` 根据现存按钮的分组身份协调增删及顺序，不再随每次名称、计数或目录响应清空重建整栏；末尾新建按钮同样复用。存活按钮的事件只注册一次，右键操作按身份读取最新分组，不保留过时名称。元数据只更新有变化的提示文字及 `aria-label`，保留 DOM、焦点和当前滑块过渡；真正的增删/重排才请求立即校准。滑块观察器忽略固定定位气泡内部文字及自身装饰 DOM 的变动，只有相关节点移除才扫描并释放旧入口监听。该改动消除源码中可确认的重建、重复绑定及失效路径；没有改动形变、反色轨道或添加动画循环，也没有实测帧率收益。

局部 ResizeObserver 通知现只触发重新测量，保留载体和反色字形轨道正在进行的过渡。此前专注与最近页交接可能使宿主高度变化 1px，监听器随即关闭过渡，导致设置为 800ms 的滑块也提前到位。窗口缩放、导航滚动、结构变化及隐藏恢复仍立即校准；不增加圆点专属时长，不改变 40ms 内容合并窗口。完整首页行为套已补充默认 414ms 和 800ms 的专注→最近→专注，以及实际宿主减少 1px 后保留原动画与反色对齐的用例；按用户要求未运行这些新增回归，也未重新打包。本次修复不新增已通过验收或性能改善的结论。
