# 笔记正文切回后滚动跳动 · 2026-10-14

本次确认并修复了“画布 → 笔记 → 静置几秒后正文和滑条移动几像素”的一条原因。生产修改仅在 `assets/styles.css`，没有修改 Markdown、保存、历史、后端、CodeMirror vendor 或用户配置。

## 原因与证据

原共用工作区动画入场从 `scale(.992)` 到 1，出场结束为 `scale(.996)`。笔记正文和表格跟随整个工作区缩放，CodeMirror 会在入场时读取到约 `.99187` 的测量比例。CSS transform 结束不改变元素的布局尺寸，ResizeObserver 不一定因此安排新的测量；动画中的块高度可能继续保留到下一次实际测量。

包含两个表格的隔离正文中，首次缩放测量使编辑器内容高度从 3794 变为约 3810 像素。之后恢复到比例 1 时，CodeMirror 自身的滚动锚点补偿写入 `scrollTop≈503.70`，浏览器取整为 504。记录的写入栈来自 CodeMirror `measure()`，并非保存后重新加载正文或表格导航命令。

使用 Git 基线 `acf9484` 的 CSS，真实浏览器切到画布、切回笔记、等待 4.5 秒，再触发公开的 `view.requestMeasure()`：滚动位置稳定复现 **500 → 504**。这次延迟测量代表正常测量入口，不修改编辑器私有状态；旧高度也可在后续交互或测量中被校准，因此跳动时机有偶然性。

## 修复

共用四个进退场关键帧的缩放值改为带原默认值的 CSS 变量。只在 `.note-workspace` 设定入场和出场比例为 1；笔记的水平平移、透明度、时长、缓动和快速反转继续沿用原流程。其他工作区使用原默认比例。

笔记在整个切换过程中保持真实 CSS 像素测量，既不锁定滚动，也不阻止表格、公式、图片和编辑器正常重测；没有额外计时器、监听、动画循环或持久化偏好。

## 验证

使用本机已有 Node/Playwright、Edge 155.0.4283.45 和 Python，所有笔记与浏览器偏好均为一次性临时库。计数、scrollTop 写入栈和测量探针仅由测试注入。

- `node tests/note-scroll-browser.js`：含表格正文与普通正文各三轮画布往返，静置并延迟测量；修复后 **500 → 500**，没有短暂滚动偏移，动画测量比例保持 1。真实表格拖选、源码/阅读模式、非整数布局宽高、快速返回和低动态保留原滚动位置，复用同一编辑器，Markdown 不变；真实滚轮仍可滚动。
- `node tests/note-scroll-browser.js --baseline`：从 Git 读取旧 CSS，预期失败于 500 → 504 的滚动位置断言，不回退工作区文件；`--diagnose` 可保留全部诊断场景而不拦截偏移。逐次测量与滚动写入保存在测试输出目录的 `scroll-report.json`。
