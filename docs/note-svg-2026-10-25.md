## 实现与边界

- `note_svg.py` 使用标准库 Expat 在有预算的单次解析中验证 SVG。`notes_library.py` 的 `_check_note_image_content()` 供上传、目录导入和已有 SVG 读取共用；栅格文件头检测保持独立，AI 原有校验不受影响。
- 支持普通路径、形状、文字、内联样式、文件内的渐变/裁剪/引用、只声明 `viewBox` 的图片，以及常见 Inkscape/Sodipodi 元数据。要求 SVG XML 命名空间；XML 声明和内建转义可用。
- 首版拒绝脚本、事件属性、SMIL/CSS 动画、`foreignObject`、DTD/自定义实体、处理指令、外部 href/url 引用、嵌入 data 图片，以及 CSS at-rule/转义。校验失败明确报错，不偷偷删除内容或改写图形。
- SVG 上限为 4MiB、10,000 元素、64 层。可识别的绝对宽高沿用 32768 单边/64Mi 像素预算；`viewBox` 是绘图坐标，不按像素面积限制。前端在文件读取前拒绝超大 SVG，后端独立复核；已有文件最多读取预算加一个字节。样式注释和 URL 使用顺序查找，避免未闭合分隔符的重复回溯。
- `/api/note-asset` 的 SVG 响应附带 `Content-Security-Policy: sandbox; default-src 'none'; style-src 'unsafe-inline'` 和 `X-Content-Type-Options: nosniff`；200、206、304、416 均保留防护，直接访问图片 URL 也不能运行脚本或加载外部资源。
- 上述是输入与结构预算，不是浏览器/GPU 内存硬上限；复杂路径和滤镜的实际渲染仍由浏览器负责。普通文字及栅格图片不解析 SVG，不新增常驻缓存、Worker 或动画循环。
