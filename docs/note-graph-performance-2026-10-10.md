# 笔记图谱标签页与共享引擎验证

日期：2026-10-10 初次移植，2026-10-11 更新透明标签页。测试使用本机 Edge、宿主 Playwright 与 bundled Python，所有 API 测试均使用一次性 `RELATUM_DATA_ROOT`，未打开真实笔记库。未重新打包桌面程序。

## 实现与数据边界

笔记工具行的“浏览”后提供图谱入口，以固定特殊身份 `relatum:graph-tab:v1` 在原标签栏维护唯一图谱页，重复点击仅激活，图谱、正文及浏览结果互斥。图谱占满标签栏下的区域，透明背景显示工作区底色，不再使用遮罩、浮窗阴影、透明度、拖动及尺寸控件；右上角保留舒展、复位及笔记本入口，窄窗另有目录入口。范围以左树选中的笔记本为准；默认本排除 `CustomNotebook`，自定义本只扫描自身子树，未选择本时入口禁用，已有图谱标签显示选择提示。每个已有 Markdown 文件都是节点，包括孤立笔记；标题使用完整文件名 stem，常显，悬停显示完整路径。点击节点激活已有或新建 Markdown 标签，图谱标签保留；失败继续显示图谱。

进入图谱先等待标题/目录改名、候选、表格及内嵌画布交接，保存当前本待保存正文，失败保留原编辑现场。进入图谱临时收起右栏，图谱侧栏只显示笔记本；返回正文恢复原开关及页签，临时状态不写入原笔记本偏好。特殊标签身份参与已有排序、关闭、快捷键和恢复，文件读取/重命名/保存/外部刷新跳过该身份。

`note_graph.py` 专门解析 Wiki、行内及引用式 Markdown 链接。代码、前言、注释、公式、图片、转义示例不参与，列表、引用和表格中的真实链接保留。跨本、缺失、歧义、外部和自引用不生成关系，同一对笔记合并为无向边。原双链面板和移动重写规则保持原语法。

`GET /api/note-graph?root=…[&signature=…]` 复用现有内存增量索引，只保存引用及元数据，不常驻正文。扫描及失效清理限定当前本；无变化复用结果，只有正文变化且拓扑不变时签名也不变。读取不完整返回 `statistics_incomplete`；初次失败显示错误和重试，后台刷新失败保留同本最后一次正确图谱。快速切本在请求前释放旧本数据，避免旧图谱出现在新本标题下。

后端响应缓存上限为 24 本及估算 16MiB，估算为 `(拓扑 JSON UTF-8 字节 + 128 wrapper/signature 字节) × 2`，属于保守预算而非精确 Python 堆测量，不含已有文档索引；超预算的单项可响应但不驻留。标签测量仅按当前图谱缓存，离屏 DOM 回收池最多 256 项，销毁清空全部测量及 DOM。

笔记图谱不再加载 `graph-window.js`，真正查看时才加载共享 GL、引擎及适配器；仅恢复隐藏标签不加载模块、不创建隐藏引擎。切页、浏览结果、离场和页面隐藏立即释放标签、绘制监听器与 GPU/context，迟到响应核对当前本和会话。图谱标签存在时，前端另以 LRU 保留最多 24 本及估算 16MiB 的正确拓扑、节点坐标、相机与待收敛标记，预算为 `(场景 JSON UTF-8 字节 + 128) × 2`，不含活跃绘制资源、DOM 或正文；超大单项不缓存。返回恢复按本视角，拖动后尚未收敛的布局继续有限收敛。成功改名映射受影响会话，删除清理，其他本改名不重建当前图谱。关闭图谱标签或 `pagehide` 清空会话，重启后首次打开重新布局取景；旧 `canvas:noteGraphViews:v1` 不再读取或写入，坐标不写文件、历史或偏好。共享 `restoreView` 校验有限数值、限制缩放并停止旧相机动画，保持相机零实例失效。

解析压力回归还覆盖约 4MiB 的未闭合语法。数学/反引号闭符与 Markdown 目的地、标题闭符通过预索引查询，失败目标不重复扫描全文尾部。重复 `[x](`、平衡外括号但未闭合 `a.md` 引号标题、未闭合角括号目的地，最终隔离样本分别为 1.873、1.900、1.501 秒，均无引用；1/2/4/8KB 重复 `[x](` 为 0.000636/0.000840/0.001751/0.003316 秒。此前该失败目的地路径在 8KB 已达约 1.32 秒，修复后不再呈平方增长。另三组约 4MiB 未闭合数学及不同长度反引号初轮样本为 1.611/1.563/1.256 秒。此为后端首次或真实变化时的解析，非前端交互帧耗时；最坏大文档首次统计仍会等待。路径的 NFC/大小写折叠碰撞视为歧义，不任意选择目标。

## 共享引擎对照（2026-10-10）

`tests/graph-instance-cache-browser.js` 在同一 Edge 页面交替关闭/开启实例缓存，使用 150/1500/3000 节点与 N−1 条边，布局稳定后测 91 个相机交互帧。此对照只包含共享 WebGL 几何，不包含笔记 DOM 标题。Shader 编译先于交互 CPU 区间，避免首次编译混入结果。所有样本的交互 P50 约 16.7ms、P95 不超过 17ms，长任务为 0，闲置绘制为 0。

静态外观样本：

| 节点 | 上传次数（关→开） | 上传字节（关→开） | 交互 ScriptDuration ms（关→开） |
| ---: | ---: | ---: | ---: |
| 150 | 182 → 0 | 1,252,524 → 0 | 19.636 → 15.970 |
| 1500 | 182 → 0 | 12,554,724 → 0 | 34.680 → 18.870 |
| 3000 | 182 → 0 | 25,112,724 → 0 | 47.898 → 15.413 |

3000 节点静态样本的交互 JS CPU 时间下降约 68%。帧间隔受本机约 60Hz 调度限制，这些结果说明减少了工作量，不能宣称整宿主帧率提升或 GPU 显存下降相同百分比。

时间驱动节点样本仍每帧刷新节点外观，缓存只省掉未变化的连线翻译与上传。三档均由 182 次上传降到 91 次，边样式调用为 0；3000 节点上传字节为 25,112,724 → 15,288,000，交互 ScriptDuration 为 182.117 → 160.129ms。原画布呼吸、漂移与粒子，星图脉动及入退场，继续由已有调度驱动；缓存本身不增加 RAF。

原始报告默认写临时目录：`relatum-graph-instance-cache-2026-10-10.json`；可靠回退报告为 `relatum-graph-instance-fallback-2026-10-10.json`。回退实测：取得 WebGL context 后模拟着色器失败，新 canvas 创建 Canvas2D，旧 context 释放、program 为 0，常显 DOM 标签正常。

## 透明标签页面积对照（2026-10-11）

当前 `tests/note-graph-performance-browser.js` 使用生产适配器、生产标签栏/目录布局 CSS、中文合成标题及真实 WebGL2。在同机 Edge 154.0.4258.62 的 headless 环境完成 150/1500/3000 节点、N−1 边、DPR 1/2 共 12 个面积样本，每项布局稳定后取景并测 90 帧平移。相同启动参数的图形查询为 ANGLE / Intel UHD Graphics / Direct3D11。对照仅改变绘制区域，两个面积都使用当前引擎与实例缓存；不等于旧版完整浮窗与新版完整工作区的全量性能对比，也不包含 API/磁盘扫描。

旧浮窗 stage 为 1160×702 CSS px；1920×1080 测试窗口中的标签页 stage 为 1628×948，面积约增至 1.90 倍。DPR 1 后备像素为 814,320→1,543,344；DPR 2 为 3,257,280→6,173,376。目录及标签栏保留，右栏默认收起。大图可能把节点放入角落的扩大命中半径，测试通过引擎命中查询确认从空白处起手，确保测量的是平移。

| DPR | 节点 | 90 帧 JS CPU ms（浮窗面积→标签页） | 样式计算 ms | P95 帧间隔 ms |
| ---: | ---: | ---: | ---: | ---: |
| 1 | 150 | 30.094 → 48.171 | 12.557 → 15.142 | 18.5 → 17.9 |
| 1 | 1500 | 52.231 → 67.558 | 23.600 → 23.351 | 17.3 → 17.8 |
| 1 | 3000 | 76.463 → 82.938 | 29.901 → 29.060 | 34.2 → 33.9 |
| 2 | 150 | 38.366 → 37.650 | 14.375 → 13.270 | 18.7 → 17.9 |
| 2 | 1500 | 54.901 → 64.645 | 22.166 → 28.280 | 17.6 → 17.8 |
| 2 | 3000 | 72.382 → 87.853 | 26.462 → 27.360 | 33.6 → 34.1 |

150/1500 节点的 P50 为 16.7ms；3000 节点在 DPR 1 两种面积下均为 17.3ms，在 DPR 2 为 17.9→18.2ms。面积增大确实增加后备像素，CPU 与布局成本会变化，不能承诺每台设备或每个图谱固定 60fps；本轮 3000 节点两种面积都有约 34ms 的尾部帧。

全部样本的平移节点/连线实例上传次数与字节数均为 0、文字重新测量为 0、长任务为 0、稳定后 RAF/绘制为 0，隐藏后 GL context/buffer/program 及标题 DOM 均为 0。每项只有 90 次父 matrix 写入，已有静止锚点不改样式；3000/DPR 2 的标签页样本有一个此前被裁剪的标题首次进入视口，产生 3 次初始化样式写入，不能误算为逐帧更新全部锚点。视口相交标题全部显示，未用密度/缩放阈值隐藏；离屏回收池不超过 256，返回复用测量。边界进出仍产生 DOM 挂载和布局工作。

原始报告：临时目录 `relatum-note-graph-tab-performance-2026-10-11.json`。同脚本缓存回归通过 30 本 LRU 淘汰至 24 本、估算字节上限、超大单项跳过、相机与坐标恢复、尚未收敛布局续接、无关本改名不重建、改名映射、删除/关闭清理，以及迟到请求和离屏删除后的测量释放。

## 验证与剩余限制

专项 Edge 验收 `tests/note-graph-browser.js` 覆盖完整模式、仅笔记、禁用内嵌画布、WebGL 不可用、锁定 WebGL 后 shader 失败五种组合；覆盖透明满幅、唯一标签、重复入口不重建/复位、MD/空白/浏览结果切换、快捷键、中文长标题及固定字号、同签名 DOM 复用、各本同名隔离与视角、孤立与空本、右栏及磁盘偏好恢复、外部新增、保存失败、Chromium 原生预编辑、节点打开失败、扫描及脚本失败重试、迟到响应、快速切本、改名/删除范围回退、离场与 visibility/pagehide 信号释放、重启恢复和隐藏恢复零模块请求、深色英文窄窗及生产脚本入口。笔记运行时明确等待 Markdown 解析器后再创建编辑器，避免从恢复图谱/空白页返回正文时遇到解析器尚未就绪。

共享引擎回归通过 `graph-presolve-regression.js` 与 `graph-instance-cache-regression.js`，覆盖单帧合并、缓存类别、容量、样式/位置/主题、入场、粒子与漂移清理、数据替换后的旧手势失效及回退。现有两种 `resource-lifecycle-browser.js`、`feature-profile-browser.js`、`note-notebooks-browser.js`、`note-view-state-browser.js`、工作区与快捷键契约回归通过，功能裁剪的 15 项 Python 回归也通过。启动器配置、实例、壁纸与运行路径的 43 项 Python 回归通过。

后端图谱、笔记库、笔记本、内嵌画布目录与画布数据层重新运行 104 项 Python 回归，通过（含 1 项既有跳过）；覆盖解析、编码/同名歧义、范围、孤立节点、关系去重、读取失败、缓存复用、容量预算、稳定签名及原功能兼容。`note-graph-performance-browser.js --regression-only` 可独立复验场景缓存与迟到请求，不执行性能采样。生产不暴露测试钩子，计数探针仅由测试路由或脚本内容注入。

宿主 bundled Python 缺少 `pywebview` 和 `clr`，原生启动器测试不能在此环境完整通过：直接启动预期实例冲突提示，实际先提示桌面依赖未安装；快捷启动用例因此停在原生提示，超时终止测试进程；WinForms 用例因 `ModuleNotFoundError: clr` 失败。真实 mutex 用例通过。本任务没有修改这些原生启动器路径，也没有用这组结果宣称桌面已验收。

Chromium CDP 原生预编辑覆盖页面的候选等待流程，不替代 Windows WebView2、微软拼音真实候选窗及实际高刷新率屏幕验收。性能数据为本机单轮样本；常显长标题在密集图中可能重叠，这是遵守始终显示标题的结果，未用密度/缩放阈值隐藏标题。
