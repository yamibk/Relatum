# 笔记本显隐与设置图标

## 行为

默认 `notes` 和自定义笔记本的右键菜单均可隐藏笔记本。自定义本的隐藏项位于资源管理器入口之后、系统回收站之前；默认本只提供资源管理器和隐藏。

隐藏只过滤右侧笔记本根及其子树。完整目录集合、当前左树、正文、未保存内容、标签、搜索、双链及图谱均不因此切换或关闭。主动打开隐藏本中的笔记也不取消隐藏。全部展开/收起只作用于可见本，隐藏本保留展开记录。

笔记设置在“系统”之后新增“笔记本”，首次进入时按原笔记本顺序创建带颜色图标的复选框，以路径复用行。勾选恢复显示，不主动选中或打开笔记。全部隐藏后右栏提供说明和“管理笔记本”入口。分类及全部设置恢复均清除显隐覆盖，保留颜色；其他分类仍沿用各自恢复行为。全局设置搜索通过分类名和显隐关键词定位此分类。

设置中的“内嵌画布”改用本地 `note-icon-wallpaper`：带山景与圆点的显示器及底座。仍使用 SVG symbol，不加载外部图标或依赖。

## 数据与接口

`data/note-notebooks.json` 的版本保持 1，增加 `visible` 路径映射；仅保存 `false`。空路径代表默认 `notes`，其他键只允许 `CustomNotebook/<本名>`。旧配置缺失字段时全部显示，启动不补写默认，新本默认显示。

`POST /api/note-notebooks-settings` 接受 `visible: {路径: 布尔值}`，`false` 验证目录存在并保存覆盖，`true` 删除覆盖，也可清除已不存在本的覆盖。无效类型和越界路径拒绝整次提交，沿用原有锁及原子写入。

显隐操作立即加入既有串行配置保存链；等待时保留原生勾选框的启用状态和待提交勾选，以 `aria-disabled`、忙碌光标和列表 `aria-busy` 表达暂不可重复操作。在列表捕获阶段取消鼠标/标签点击及 Space/Enter 激活，不切换整列原生 `disabled`，避免系统控件禁用态重绘导致整列勾选框闪烁；Tab、焦点移动和 Escape 保留。未变化的说明、名称、色值、勾选及属性不重复改写，保留列表行、文本节点、焦点和滚动位置，也不改变整行透明度。成功后更新右树，失败恢复原值，不进入后台重试缓冲。颜色、界面与应用内改名的配置补丁仍沿用原合并和失败保留行为。

应用内改名迁移颜色和显隐；外部改名按旧路径缺失处理，新路径默认显示、灰色。成功回收或外部删除后，从完整目录集合识别缺失路径，后端核实不存在再统一清理颜色、显隐和展开记录。目录不可读或权限失败时保留记录。隐藏不属于删除，不触发该清理。

## 验证

- `node tests/note-notebook-visibility-browser.js`：真实右键隐藏、默认根菜单、左树/编辑器/未保存内容/标签与展开状态保留、隐藏项搜索和双链、设置行及焦点复用、键盘勾选、设置搜索、全部隐藏的管理入口、重载、分类/全部恢复、失败不重试、延迟提交与重复操作阻止、应用内/外改名及删除清理；深浅、英文、窄窗及低动态截图。
- 显隐浏览器回归还用 14 本的可滚动设置页，在深浅主题、正常/低动态下延迟真实保存，验证保存中及完成后各行透明度始终为 1，所有未变化的元素/文本节点身份保持、无子树重建，滚动位置和键盘焦点保留；覆盖取消勾选和重新勾选。另观察原生 `disabled` 属性全程零变化，并逐像素比较未操作的已勾选/未勾选框在保存前、中、后的截图。鼠标、标签及 Space/Enter 重复激活不产生 `change` 或额外保存请求，失败回退后仍可重新操作。

- `node tests/note-settings-browser.js`：六种功能组合的设置、引导、持久化和生命周期回归，分类计数增加 1，并核对内嵌画布的新图标。
