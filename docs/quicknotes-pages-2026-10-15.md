# 速记独立页面与性能验证（2026-10-15）

## 行为与数据

速记增加 1–99 数字页，沿用学习页的右缘编号外观、上下滚动区、选中滑块节奏和右键色板。中央空位保留控制台入口，控制台打开时页栏不可交互。页栏滚轮先滚动列表，到边缘后切页；台面滚轮继续缩放。

编号栏按学习页节奏即时响应：收到滚轮或点击后立即更新目标页选中态、颜色与列表定位，滑块下一显示帧更新目标，并沿用共享翻页速度与缓动。目标页与当前挂载页分离；便签、镜头、保存和撤销仍属于当前挂载页，本机当前页偏好仅在成功提交后更新。

内容切换采用学习极简清单的整体淡出/淡入：候选输入结束后，目标读取与旧便签/线条淡出并行；连续输入只更新最后目标并重置 150ms 提交等待，不重新显露旧页。数据就绪且等待完成后替换，再以透明度和轻微位移入场。重复选择同一待处理目标复用操作，返回挂载页从当前透明度恢复；最后目标加载失败时恢复原页及选中态。快速反向时，已取消的在途请求不能被复用。低动态跳过动画等待，仍等待真实数据与编辑交接。各页内容、叠摞、镜头和会话撤销/重做互相隔离，长按归档仅作用于当前挂载页。

`data/notes.json` 升为 V2，保留原顶层 `notes/edges/arrows` 数组，对象用 `notePage` 归属页面。V1 读取为第一页，不在读取时写盘。读取接口增加可选 `notePage`，返回该页及 `highestPage`；保存与归档只合并指定页，缺省第一页，沿用原锁和原子写入。每页限制 400 张便签、800 条连线和 800 个箭头；拒绝跨页连接。不可读/损坏数据返回错误，避免用空状态覆盖。

当前页、页号颜色分别使用 `canvas:notesPage:v1`、`canvas:notesPageColors:v1`；第一页镜头保留 `canvas:notesView`，其他页使用 `canvas:notesView:<页码>`。只有当前页有 DOM，其他页缓存纯数据及会话历史。保存捕获页面身份、快照和修订，相同修订的请求去重；失败保留脏状态，后续交接或保存重试。输入法候选结束后才切页，编辑监听在收尾时释放。隐藏、原生最小化和 pagehide 取消交互与未完成切页，恢复当前现场。

## 性能改动与实测

重排改为一次构建叠摞和层级索引；拖动位置及连线、划删预览每帧提交一次，原始速度与轨迹采样不丢弃。编辑延迟测量核对页面身份；连线测量反算工作区实际缩放，覆盖工作区往返与非整数台面尺寸。

使用测试主机 Edge、1440×900 隔离窗口，以 Git `a2b1e41` 中的旧速记脚本对照。96/400 张普通和叠摞便签各测三轮，每段投递 640 次指针移动；以下为三轮中位数，耗时包含测试事件投递与页面工作。

| 场景 | 旧版 | 新版 |
| --- | ---: | ---: |
| 400 张叠摞：拖动样式写入次数 | 2704 | 648 |
| 400 张叠摞：拖动主线程总耗时 | 2414ms | 1350ms |
| 400 张叠摞：划删路径更新次数 | 641 | 17 |
| 400 张叠摞：划删主线程总耗时 | 1382ms | 512ms |
| 96 张普通：划删主线程总耗时 | 1208ms | 235ms |

真实重排函数的模拟 DOM 对照保留了普通、收拢与展开状态的全部位置/层级结果。400 张叠摞每次重排原有 240200 次便签数组访问，改后不再逐便签重扫数组；该算法测试的耗时中位数约为 14.07ms → 2.01ms，不能当作整页帧耗时。

所有组合静止后均无待执行 RAF。普通小页的纯脚本时间、400 张密集叠摞的帧间隔 P95 未在每组下降；本轮收益主要体现在减少重复计算、DOM 写入和主线程总工作量，不提供固定 FPS 保证。

## 验证入口

- `python -B -m unittest discover -s tests -p test_quicknotes_pages.py`：旧格式、按页合并/归档、容量、跨页引用、失败保留数据、功能裁剪。
- `node tests/notes-pages-browser.js`：真实保存与归档、独立镜头/历史/搜索、连续切页、失败重试、候选保护、页号色、中央控制台、边界、最小化、语言/主题/窄窗/低动态、重启、静置及大 UTF-8 请求。
- `node tests/notes-wheel-browser.js`：相同真实滚轮对照学习页的慢滚、连续与反向、细粒度累计和超时、两档滑块速度；检查事件内选中态、下一帧滑块目标、连续滚动单次淡出及只挂载最终页，另覆盖慢请求/失败回退、同页去重、未缓存页快速反向、候选保存身份、隐藏/最小化/离页、低动态、溢出列表及 1/99 边界，静置零 RAF。配置 `RELATUM_NOTES_WHEEL_BASE_REF=3df8d77` 可加载旧脚本，在首项即时反馈断言复现原延迟；探针只注入测试，不进入产品代码。
- `node tests/notes-browser-performance.js <报告.json> regression`：原速记行为、几何跟随及新增非整数台面尺寸回归。
- `node tests/notes-hotpaths-browser.js [报告.json]`：上述三轮对照，基线可由 `RELATUM_NOTES_BASE_REF` 指定；模拟 DOM 探针及浏览器计数均只存在测试中。
- 浏览器入口使用测试主机已有 Playwright 和 Edge，配置 `RELATUM_PLAYWRIGHT`、`RELATUM_PYTHON`，可选 `RELATUM_EDGE_PATH`；全部内容和服务数据使用新建临时目录，结束关闭服务。
