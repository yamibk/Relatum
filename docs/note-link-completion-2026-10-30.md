# 笔记双向链接补全

## 行为与设置

实时预览、源码与表格单元格使用同一文件候选控制器。输入第二个 `[` 立即查询，后续输入合并 150ms；关闭自动显示后可以在目标部分按 Ctrl/Cmd+Space 开启一次候选会话，此会话继续随输入筛选。上下键选择，Enter/Tab/鼠标接受，Esc 关闭。最多返回 50 项，视窗约 8 行，超出时提示继续输入。

只推荐 Markdown 笔记，不包括当前文件、附件和画布。代码、公式、注释、前言、`![[`、别名和标题/块后缀不触发文件补全。没有匹配不会创建文件，仍可保留未解析链接并沿用原点击创建流程。已有标题/块后缀、别名保留；接受候选补齐括号并将光标放到链接之后。中文候选期间不查询、不接受，原输入链完成后再筛选。

“笔记设置 → 编辑”提供自动显示、候选范围、排序方式、同时搜索正文。偏好键为 `canvas:noteLinkCompletion:v1`，默认 `{automatic:true,scope:'all',sort:'smart',includeBody:false}`；范围另有 `notebook/folder`，排序另有 `recent/modified/name`。目录范围包含子目录，默认本根目录不跨入自定义笔记本。参数只存本机偏好，启动不写默认，写入失败保持原值。编辑分类恢复和全部恢复包含此键，桌面通用 `canvas:` 快照自然覆盖此键。

智能推荐空输入按真实访问时间优先，再以最近修改补足；与既有最近文件取访问/修改较新值的方式独立。输入后依次按名称完全匹配、名称前缀、名称包含全部词、名称/路径组合匹配、需要正文参与匹配排序。同档依次比较当前目录、当前笔记本、最近访问、最近修改、自然名称和路径。其他排序直接应用所选规则，但正文参与命中始终排后。名称指文件名，不取正文 H1 或前言别名。

## 数据与接口

复用 `/api/note-query`，增加 `mode:'link-completion'`。请求包含 `q/sourcePath/scope/sort/includeBody/recent`；`scope` 沿用 `{kind,path}`，`recent` 沿用最多 200 条访问记录。`q` 最多 512 字符、32 个空格分隔词，NFC/casefold 匹配，引号等按字面处理。可带 `selectedPath` 只读复核所选目标。

响应包含 `items/hasMore/generation/index`。条目含 `path/title/location/notebook/insertTarget/match/titleHighlights/pathHighlights`；`match` 为 `name/path/body`，正文命中另含短 `excerpt`。`generation` 为目录版本，不提供无限翻页。名称/路径查询不获取正文与位置映射，只有最终选中的正文命中才从 SQLite 读取短摘要；所有热查询不遍历目录、不读 Markdown 文件、不取得 Markdown 写锁。

现有 FTS5 trigram 和短字符项提供候选，元数据条件明确排除仅正文命中。短字符 FTS 使用 `detail=none`，因此使用现有全字段倒排加索引元数据验证，不添加不受支持的 FTS 列过滤。无需新数据库、表或索引迁移。

`insertTarget` 在同一快照内按现有 wiki 规则验证：根路径完全匹配优先，否则仅唯一同名目标可用短名称。即使候选限制在单本或目录，也检查全库歧义。其余使用完整库内路径；百分号和 wiki 分隔字符编码一次，保持原解析器的单次解码规则。接受时通过 `selectedPath` 复核，目标失效则保留原文并刷新候选。仅最终替换写入编辑历史，表格通过原单元格提交通道进入父编辑器的一次独立撤销。

## 资源与生命周期

`assets/note-link-completion.js` 管偏好、共享编辑器扩展及设置行；加载和静态资源授权归 `notes`。主编辑器提供既有语法/公式/注释保护及原生输入交接，表格单元格复用同一扩展并保留原键盘和序列化行为。离开链接、切文档/视图、失焦、打开设置、工作区离场、隐藏、最小化和主题/语言变化均清理计时器、请求和菜单。异步返回核对编辑器、文档、选区、路径和操作版本。无全库前端镜像、轮询、新观察器或常驻 RAF。

补全使用已锁定的 `@codemirror/autocomplete@6.20.3`，离线入口增加标准补全与 tooltip 导出，关闭默认按键和本地模糊排序；排序由 SQLite 决定。原版本和锁文件不变，通过已有维护构建脚本重建离线资产并更新 SHA-256。菜单复用四种主题和深浅表面色；设置下拉复用 `review-controls`，置于同一 dialog 裁切区之外。

## 验证

候选菜单虽然挂在 `document.body`，其滚动列表仍复用笔记正文的滚动条变量与样式：透明轨道、细圆角滑块、无两端箭头，深浅色沿用笔记配色。Chromium 分支恢复标准属性为 `auto`，让既有 `::-webkit-scrollbar` 细节生效；其他引擎沿用标准 thin 回退。无新增滚动控制器或监听。专项浏览器启动保留原生滚动条绘制，避免 headless 默认隐藏导致截图漏验。

- `python -m unittest tests.test_note_link_completion tests.test_note_index_api`：匹配、范围、各排序、全库重名、根路径优先、保留大小写的显示位置、转义字符实际解析、删除后复核、50 项限制、零文件 I/O、输入和权限边界。
- `node tests/note-link-completion-browser.js`：真实 API/Edge，临时笔记和 WebView 偏好；实时预览、源码、表格、中文 Chromium 合成输入、手动候选会话、键盘/鼠标、独立历史、别名/后缀、主题/窄窗、设置持久化/恢复/失败回滚、迟到响应和重试。
- `python tests/note-link-completion-performance.py --counts 10000 50000 --output <临时报告>`：一次性真实 Markdown 库，记录目录/正文全部索引后的热查询 p50/p95、并发查询时的原子保存延迟；对热查询安装目录扫描和正文读取失败探针。
- 相关回归：笔记索引/库/浏览/笔记本/功能权限/桌面偏好、搜索三种外壳、表格交互、设置、编辑器/主题/高亮契约。常规入口 `tests/run-note-checks.ps1` 已登记本专项。

Chromium 合成输入验证不代表微软拼音候选窗口已人工验收；源码验证不代表发布 EXE 已重新打包。
