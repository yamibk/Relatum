# 复习评分与下拉性能复核（2026-10-16）

本次只调整 `assets/review.js`、共用下拉 `review-controls.js / review-controls.css` 及旧统计动效样式。后端接口、数据库、评分间隔、导入协议和事务保持原样，没有新增依赖。

后续每日补练与评分收据改动见 [计划复习规则](review-scheduling-2026-10-16.md)。本记录保留性能改动的原始对照口径；当前回归已适配显式“重试保存”，沿用按钮、焦点、下拉及闲置检查。

## 问题与行为

评分没有重建页面。原先 `marking` 会让评分和换卡按钮进入原生 disabled，命中 38% 透明度，同时使当前按钮丢失焦点；保存结束后恢复，形成明显明暗闪动。现在提交中保留按钮节点、颜色和焦点，用内部锁、`aria-disabled` 和操作区 `aria-busy` 表达等待；没有可操作卡片时才使用原生 disabled。保存成功后推进一张，失败保留原卡片和草稿；评分键的自动重复、双击第二次点击及输入法候选均不评分。

评分、换卡按钮引用常驻，统计、提示及卡片元数据只写实际变化。数字反馈改用 440ms 的有限 Web Animation，取消旧动画后重播，结束释放效果；不再通过 `offsetWidth` 强制布局。数字及 +1 提示在离页、隐藏、原生最小化和低动态切换时清理。换卡仍直接显示内容。

旧下拉先创建窗口列表，再设置浮层最大高度。初次窗口化的滚动容器尚无约束，会短暂挂载所有 1000/10000 项，后续帧才降到 16 项。现在先确定宽度、高度上限与实际滚动视口高度，再初始化列表；也避免空容器 `clientHeight=0` 触发共享列表的 600px 回退。窗口列表本身未修改。

搜索复用已有列表与存活行；选项按值复用，只有选项或语言真正变化才重建规范化搜索缓存。`setOptions(select, entries, value)` 更新选项，`refresh(target)` 接收外部选项变化，`sync(target)` 只同步取值和禁用状态。有效匹配保留键盘高亮，非空查询跳过默认未分组的优先高亮；新卡组仍只在原业务正式保存时创建。

悬停每帧只处理最新候选，命中不变不写 DOM，变化只改旧、新高亮行及当前无障碍引用；点击与键盘确认同步读取候选，并取消待处理悬停。定位只响应相关祖先滚动、真实尺寸及布局过渡，合并读写；颜色、透明度和阴影过渡不重新定位。触发器取消按下缩放，保留颜色、箭头与淡入。临时尺寸观察器、监听、窗口列表和待处理帧随菜单关闭释放，没有新增常驻 RAF。

## 同环境对比

基线 `ef3ae35`，由测试从 Git 读取旧源码/CSS，不切换工作目录。使用同一个隔离服务、Windows headless Edge 155.0.4283.45、Node v22.21.0；菜单为 1280×900 CSS 像素、DPR 1，每种规模各三个新页面取中位数。最终性能测试与导入回归顺序运行，未并行执行压力测试。

“打开”是 `control.open()` 的同步耗时，包含显示所需的同步布局；不包含选项夹具构造。峰值通过 MutationObserver 记录整个首次挂载过程，不只在动画结束后检查。表中 DOM 仅指浮层的选项行，隐藏原生 select 的表单选项继续保留。

| 选项数 | 旧打开 / ms | 新打开 / ms | 旧浮层行峰值 | 新浮层行峰值 |
| ---: | ---: | ---: | ---: | ---: |
| 20 | 5.4 | 5.7 | 20 | 20 |
| 200 | 7.6 | 7.5 | 200 | 200 |
| 1000 | 20.3 | 6.6 | 1000 | 16 |
| 10000 | 163.6 | 10.4 | 10000 | 16 |

选项准备被前移且单独计时：万项控件初始化中位数从 3.2ms 变为 11.4ms；加上首次打开，两段中位数合计约从 166.8ms 变为 21.8ms。之后取值、禁用状态及相同条件同步不会重复生成搜索缓存。小菜单打开时间基本持平。

CDP Performance 在打开到两个显示帧及随后 180ms 收尾期间的测量：

| 选项数 | 旧布局 / ms | 新布局 / ms | 旧样式重算 / ms | 新样式重算 / ms |
| ---: | ---: | ---: | ---: | ---: |
| 1000 | 9.43 | 3.09 | 5.39 | 3.65 |
| 10000 | 79.62 | 3.20 | 23.32 | 3.35 |

重复移动于同一选项 200 次，四种规模的属性写入均由 200 次变为 0；新实现没有为这些相同命中申请 RAF。快速跨行移动 200 次仅申请一帧，最终高亮最后候选，属性写入 3 次。千/万项菜单打开期间的显式几何读取由 14 次降至 12 次，计算样式读取由 4 次降至 2 次；小菜单几何读取由 4 次降至 2 次。全部规模收尾后闲置 180ms 的新增 RAF 都为 0。

评分响应延迟 650ms 的旧页面中，按钮 disabled=true、透明度 0.38、焦点已丢失。新页面等待响应时 disabled=false、`aria-disabled=true`、透明度 1、焦点仍在原按钮；根、评分及换卡节点未替换。保存失败后仍为原卡片、原草稿和原计数；重复鼠标/键盘操作只发送一个请求，成功才推进一张。

这些是固定夹具的主线程和 DOM 指标，用于比较相同操作的开销，不是实际显示器帧率的承诺。
