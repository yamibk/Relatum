# Relatum 四处性能优化验收

2026-10-07。基线提交：`23cc37f1a381ec001c45746363ee5cd93a556625`。

本次只调整手写访问、研究静态投影通知、笔记文件树枚举和日记摘要缓存。保留界面、交互、HTTP API、数据格式和离线资源；星图首次布局没有改动。所有读写测试使用一次性数据根或内存 API 替身，没有连接真实用户数据。

## 修改与边界

- **主画布**：有效墨迹的 `ensureInkData()` 直接返回活体，不再随普通编辑、空画布提示或橡皮指针事件复制全部笔画点。异常容器仍规范化；初始化、导入、历史快照和恢复仍深拷压力、倾斜、控制点与折点。箭头事件继续按 ID 查找，防止捕获撤销/导入前的对象。
- **研究**：保留每秒墙上时间与原调度。没有 `current-time` 时计算返回同一结果对象，跳过无变化展示通知；普通及子电路内时间节点仍通知。连续仿真分片、单步和复位保持原实现。
- **笔记树**：用 `os.scandir` 和每个可见条目一次非跟随链接 `stat`，复用类型、顺序与元数据。符号链接及 Windows 重解析点排除，子目录进入前实时复查；目录枚举错误保持 `read_failed`，单条目消失或状态读取失败跳过。正文读取和保存路径授权不变。
- **日记**：内存只保存最多 4096 篇摘要与文件签名，不保留正文；每次仍检查文件时间、大小、设备和文件身份，重读前后签名一致才缓存。保存/删除立即失效，失败不服务旧摘要，根目录切换清空缓存，响应对象独立。超容量时保留已有有效摘要，额外项只生成本次响应，避免扫描顺序导致缓存循环淘汰。

## 前后测量

耗时是本机隔离夹具的结果，不是硬件呈现帧率，也不作为跨机器固定门槛。

### 手写访问

无头 Edge 154.0.4258.53，合成墨迹、11 次真实 `CanvasModule.notify()`；测量阶段关闭墨迹 SVG 绘制以隔离访问成本，功能回归启用绘制。

| 手写点数 | 原中位数 | 修改后中位数 |
| ---: | ---: | ---: |
| 50,000 | 1.0 ms | <0.1 ms |
| 200,000 | 3.7 ms | <0.1 ms |
| 500,000 | 9.7 ms | <0.1 ms |

修改后最慢均约 0.1 ms；原 500,000 点最慢约 14.3 ms。小于 0.1 ms 表示低于本次浏览器计时粒度。普通访问保留所有点的对象身份，不再分配与总点数相同的新点对象；历史记录仍有必要的深拷成本。

同页对比原调度与当前调度，1000 个暂停的 Clock 节点，无 `current-time`，每版采样四次墙上时间回调。

| --- | ---: | ---: |
| 四次回调的无变化文字写入 | 8,000 | 0 |

耗时包含写入计数钩子，不含随后布局/绘制。原始静态对比是内存脚本，结果在工具输出中，未保存独立原始文件。现有 1000 主动时间源验收完成 36 个完整批次、36,000 Pulse 和 113 次协作让出；RAF 中位 16.7 ms、P95 33.3 ms，仅报告，本次没有据此宣称连续仿真提速。

### 日记摘要

一次性库，每篇 7350 字符，365/2000 篇合计约 7.8/42.9 MB；每组五次中位数。基线直接从上述 Git 提交读取旧 `diary_index()`，不回退工作目录。

| 日记数 | 原版每次 | 修改后首次 | 修改后无变化请求 | 无变化请求正文读取 |
| ---: | ---: | ---: | ---: | ---: |
| 365 | 86.26 ms | 92.60 ms | 3.87 ms | 365 → 0 |
| 2,000 | 467.58 ms | 512.82 ms | 22.32 ms | 2,000 → 0 |

首次读取稍慢，因为增加读前/读后签名校验；本次收益来自后续切日、切月及相邻月份预取复用摘要。超过 4096 篇时仍需读取未缓存部分，不会无限增加内存。该测量只隔离摘要索引，其他日历聚合仍有自身成本。

## 回归结果

- 新手写回归覆盖活体访问、旧坐标规范化、压力/倾斜/箭头几何、历史独立、撤销/重做、墨迹导入及失败回滚、整笔/局部橡皮、删折点和撤销后拖端点。既有画布 changes/performance/import/ruler 回归通过。
- 研究运行时回归覆盖静态图静默、普通及嵌套子电路时间节点、增删、切页、过期回调、暂停/激活、单步和复位。八项研究脚本及后端存储回归通过；1000 时间源浏览器验收无计算/页面错误，运行状态没有写入文档。
- 笔记库专项 43 项，42 通过，1 跳过；真实 Windows junction 排除通过，真实符号链接创建因 WinError 1314 权限不足跳过，模拟文件/目录符号链接排除通过。`note-view-state-browser.js` 使用真实隔离 API 验证外部同步、DOM 复用、改名、错误恢复与保存，通过。
- 日记专项 16 项通过，覆盖解析结果、外部替换、保存/删除/失败、签名竞争、返回对象独立、并发读取及保存、缓存超容量仍保留部分命中，以及日历响应仍读取选中日期完整正文。日历三项前端契约通过。
- 非原生启动器 Python 总计 332 项，331 通过，1 项权限跳过。原生启动器四项未纳入此通过结果：宿主缺少 `clr` 和桌面窗口依赖，单独复核两项分别报缺少 `clr`、缺少桌面窗口依赖；另一次启动检查等待原生窗口，已结束该测试进程，没有修改启动器来绕过依赖。
- 修改后的 JS 语法与 `git diff --check` 通过。桌面 EXE/MSIX 未重新打包，浏览器检查不等同于物理高刷新率 WebView2 呈现测量。
