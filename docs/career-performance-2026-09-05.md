# 生涯报告滚动性能验收

2026-09-05。修改范围为 `assets/career-report.js` 与生涯专属 CSS，未修改报告统计口径、快照、用户数据或滚动偏好格式。基线是提交 `fa204e7b6fd950bf70e998c8f6a7ebb1b71dcf96`。

## 优化内容

- 滚动边界由 ResizeObserver 缓存；惯性帧只更新浮点位置，不再交替读取 `scrollTop / scrollHeight / clientHeight`。保留亚像素余量，按真实帧间隔积分，60–240Hz 下同一滚轮刻度的总位移一致。触控板、缩放、横向输入、按下滚动条与滚动键会终止旧惯性。
- 数字用预留尺寸的隐藏文本维持自然换行，独立定位的可见文本只更新原有 Text 节点。数字递增仍逐帧运行，柱条宽度与报告高度不再随数字变化。模块自管中英文文案，避免全局翻译再次扫描数字与项目名称。
- 可见性直接取自 IntersectionObserver，避免揭示前逐卡测量。已揭示的卡片离开视口时结束剩余动画并停止观察，回看显示最终态；未进入的卡片继续保留首次入场。点阵以连续四点为一组错峰，关系图连线每八条一组淡入，降低同时参与动画的对象数。
- 卡片入场结束恢复 `transform:none`；滚动时隐藏图表即时提示，停稳后保留正常悬停与键盘查看。惯性结束后才启动揭示等待计时器，缺失偏好正确使用原定的 50ms。
- 离开工作区、隐藏页面、pagehide 和实时低动态偏好切换统一清理动画、数字、惯性与观察器。重新进入、语言重绘和生成失败保留既有报告行为。

## 测量口径

本机无头 Edge 152.0.4191.62，视口 1440×900。每组 3 轮，使用新浏览器上下文与同一确定性冻结快照：24 个月、365 天、12 条排名、48 个笔记节点/120 条关系、三个点阵和月度矩阵。测试服务自行创建临时 `RELATUM_DATA_ROOT`；报告 GET/生成接口使用浏览器替身，未读取真实业务库。

首页就绪后等待 1.9 秒，再采样 13 秒。浏览器内每约 100ms 派发一个明确带离散刻度的 120px wheel 事件，经过真实生涯滚轮处理器；另有 Playwright 实际鼠标滚轮与悬停回归。两个版本都到达报告底部，报告高度均为 12,103px。帧指标是 RAF 回调间隔，不是 GPU 呈现帧或桌面 WebView2 实测。

普通组为 DPR 1、CPU 不降速；压力组为 DPR 2、DevTools CPU 4 倍降速，同时开启 timeline 追踪。这是用于放大开销的测试条件，不能等同于具体低端机器。表格采用最后完整三轮的中位数，最长帧列取三轮最大值。

| --- | ---: | ---: |
| RAF 帧间隔 P95 | 16.9ms | 16.9ms |
| 最长帧（三轮最大） | 33.3ms | 18.0ms |
| 布局总耗时 | 204ms | 123ms |
| 脚本总耗时 | 176ms | 154ms |
| 主线程任务总耗时 | 2.332s | 2.109s |
| 滚动区高度/视口高度读取（各） | 658 次 | 0 次 |
| 数字文本节点替换 | 3,542 次 | 0 次 |

普通组布局耗时约下降 40%，主线程任务耗时约下降 10%；两组 P95 均接近 60Hz 的帧预算，不能据此声称帧率提高 40%。优化后的零文本节点替换表示更新常驻 Text 节点，数字内容仍逐帧变化。

| 压力组，每轮 13 秒 | 原版 | 优化后 |

压力组布局耗时约下降 30%，Paint 次数约下降 36%；它仍存在长帧，主线程总耗时也没有稳定下降。重复压力测量有明显波动，不能承诺消除所有掉帧。绘制/布局工作减少与端到端帧率改善是不同指标。

## 复现

测试工具无需为应用安装依赖。`RELATUM_PLAYWRIGHT` 指向测试主机已有 Playwright 模块，可用 `RELATUM_EDGE_PATH` / `RELATUM_PYTHON` 覆盖测试程序位置。

```powershell
$env:RELATUM_PLAYWRIGHT = '<已有 Playwright 模块的绝对路径>'
$env:RELATUM_CAREER_ROUNDS = '3'
node tests/career-browser-performance.js '<优化后结果.json>' regression

# 原版素材由 git 只读提取，工作目录不回退。
$env:RELATUM_CAREER_BASELINE = '1'
$env:RELATUM_CAREER_BASE_REF = 'fa204e7b6fd950bf70e998c8f6a7ebb1b71dcf96'
node tests/career-browser-performance.js '<原版结果.json>'

# 压力组；原版和优化后各运行一次，切换 BASELINE 为 1 / 0。
$env:RELATUM_CAREER_CPU = '4'
$env:RELATUM_CAREER_DPR = '2'
$env:RELATUM_CAREER_TRACE = '1'
node tests/career-browser-performance.js '<压力结果.json>'
```

普通组需清除压力组的 CPU/DPR/TRACE 环境变量。工具只连接自己启动的临时数据根，正常结束或测试失败时均关闭浏览器与测试服务。`RELATUM_CAREER_SKIP_BENCHMARK=1` 可仅进行短采样和行为回归，该短采样不用于性能对比。
