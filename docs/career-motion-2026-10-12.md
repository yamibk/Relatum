# 生涯数字动效调整与验收

日期：2026-10-12。基线为 `0ad5fdf9138ffdce7fcc11e9bc2bab45452b1d69`；本轮只修改生涯指标计数、显示格式、触发和会话生命周期，未改变用户数据、后端接口、图表数据或共享图谱引擎。

## 实际行为

- 数字由 720ms 的四次方急减速，改为 1500ms 的 `t²(3−2t)` 柔和累计。旧曲线在 180ms 已达到约 68.4%；新曲线此时约 4%，750ms 达到一半。
- 不限帧，复用原有限 RAF 调度器，按实际经过时间推进；掉帧不会人为拉长计数时间，滚动暂停期间不计时，相同文字不写入。
- 日期、连续天数、字词和文件数量只显示整数。时长按最终值固定秒/分钟/小时，最多一位小数；图表提示及精确明细的格式不变。
- 挂载前显示零并预留最终尺寸，占位设置 `aria-hidden`。真实视口至少 15% 可见才开始；首次页面淡入开始后等待 200ms，延迟不包含此前构建报告的时间。图表提前挂载规则不变。
- 七项指标的已播放身份只保留在冻结报告会话内。滚动返回、工作区返回和筛选/主题/语言重建不重播；新生成成功后重置。零和未知值静态显示。
- 隐藏、离场、最小化和 pagehide 取消计数、已开始的指标落定。低动态立即显示最终值，运行中开启低动态同样取消当前及待开始计数。无新增存储或持续动画。
- 移除未调用的数字落定动画和专属旧样式。检查柱形、排名、折线、面积、月份圆点、密集图表、图谱、悬停及滚动惯性后，没有发现需要额外调整的可复现动效衔接问题，保留原参数。首次 CSS 图表动画含错峰至多 1050ms，原 1100ms 收尾没有提前截断。

## 功能验证

- 六组后端测试共 54 项通过；生涯契约、使用采集和图谱实例缓存回归通过。
- `career-number-regression.js`：模拟 30/60/120Hz、掉帧及暂停，验证单调累计、时序、整数、固定单位、单个文字节点、重复写入过滤、取消和低动态。
- `career-number-browser.js`：真实 Edge 155.0.4283.45，使用临时报告和生产生命周期/章节/CSS。启动延迟实测约 200–202ms；宽窗和 430px 窄窗大数尺寸稳定；覆盖 10% 不启动/跨 15% 启动、滚动暂停、快速滚动、零/未知、小数时长、重建和返回、重新生成、隐藏/最小化/pagehide、动态低动态切换。静置新增 RAF 为 0，浏览器异常为 0。
- `career-chart-interaction-browser.js`：WebGL 和 Canvas2D 均通过，覆盖全部图表、首次/回看、悬停与键盘提示、图例 DOM 复用、真实图谱节点/关系命中、低动态和深色窄窗。热力图基础绘制仍为 365 次，同一格提示文字重复写入为 0。
- `career-v2-browser.js --webview2 --checks-only` 及 `--webview2 --fallback --checks-only` 均通过（WebView2 154.0.4258.62）。真实桌面壳验证筛选/重建不重播，并在新报告计数期间调用原生最小化、核对最终值、还原后不重播。此模式覆盖功能和释放，不采集压力性能。
- `resource-lifecycle-browser.js` 默认预加载和 `--on-demand` 两组均通过，关闭图谱 GPU buffer 为 0，雨声暂停源和关闭/过期后 PCM 均为 0。第一次启动未设置 Edge 路径而找不到 Playwright 自带浏览器；配置原 `RELATUM_EDGE_PATH` 后完成验证，没有安装或下载浏览器。

## 大数据三轮对照与限制

Windows / i9-13900HX / Python 3.12.14；两组独立执行既有 `career-v2-browser.js --large`，测量时不并行运行其他测试浏览器。每组使用 5000 篇笔记、500 张主画布、200 个研究页面、10 万条计时输入；DPR 1 普通场景，DPR 2 / CDP CPU 四倍降速压力场景。所有内容和浏览器配置均隔离，不读取真实用户库。

| 场景 | 修改前 P95，三轮（ms） | 修改后 P95，三轮（ms） | 既有目标 |
|---|---|---|---|
| 普通滚动 | 15.8 / 12.3 / 12.5 | 12.6 / 12.5 / 8.4 | ≤20ms，通过 |
| 普通拖动与悬停 | 8.3 / 4.3 / 4.4 | 8.4 / 4.7 / 8.2 | ≤20ms，通过 |
| 压力滚动 | 58.3 / 66.6 / 62.4 | 54.1 / 54.2 / 62.5 | ≤35ms，两组均未达标 |
| 压力拖动与悬停 | 25.0 / 29.2 / 21.0 | 30.0 / 24.9 / 25.0 | ≤35ms，通过 |

原始样本、平均帧率、峰值及失败断言保留在 [配对采样 JSON](career-motion-2026-10-12.json)，移除了临时数据根路径。两组的报告静置、图谱收敛后新增 RAF 和浏览器异常均为 0；完整功能流程完成后，测试因压力滚动阈值断言返回非零，不能报告为“全部通过”。

本轮轻负载采样帧率常见约 180–240fps，与 10 月 11 日约 60fps 的历史记录不同，不能将两次测量直接当成相同条件。按原脚本每显示帧推进滚动，测试节奏随实际帧率变化。压力滚动在未修改代码中同样超标，本轮没有显示本次计数重构引入明显退化；三轮样本也不足以证明统计显著的性能提升。既有极限压力瓶颈仍保留，未放宽阈值或掩盖失败。

## 复现

沿用宿主 `RELATUM_PYTHON`、`RELATUM_PLAYWRIGHT`、`RELATUM_EDGE_PATH`，真实桌面另设 `RELATUM_WEBVIEW_PYTHON`。不安装项目依赖、不替换发布 EXE。

```text
node tests/career-number-regression.js
node tests/career-number-browser.js
node tests/career-report-contract.js
node tests/career-chart-interaction-browser.js
node tests/career-v2-browser.js --large
node tests/career-v2-browser.js --webview2 --checks-only
node tests/career-v2-browser.js --webview2 --fallback --checks-only
node tests/resource-lifecycle-browser.js
node tests/resource-lifecycle-browser.js --on-demand
```
