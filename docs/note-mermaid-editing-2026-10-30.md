# 笔记 Mermaid 编辑层与 Pele 1.12.0 · 2026-10-30

## 用户行为

改动仅作用于笔记工作区。实时预览中的图表单击选中整块，双击或 Enter 展开原源码并在下方继续显示只读预览；Esc 保留修改、收起到整块选中态。点击正文按真实位置退出编辑；菜单和原生失焦保留已打开的源码和文字选区。跨过图表的正文范围选区不会自动展开源码。

整块 Ctrl/Cmd+C/X 使用原始围栏 Markdown，保留围栏字符/长度、语言别名、空白及引用前缀。剪切必须先成功写入文本再删除；Delete/Backspace 显式删除整块可一次撤销。普通源码选字与跨块范围仍复制实际所选文字；右键复用正文菜单。

表后紧邻段落行首 Backspace 进入结束围栏前的内容末尾，表前段落行尾 Delete 进入起始围栏后的内容开头；本次只交接焦点，不改正文或新增历史。多余真实空行先正常删除。文首文末没有正文段落时，只有主动进入才补齐。空、未闭合及超限围栏保持代码，纯源码模式保持原编辑规则。

闭合图表临时语法错误时，编辑预览和收起的图表均可复用当前块上次成功图，并显示错误提示；第一次没有成功图时显示错误。候选文本只留在输入宿主，确认/取消后再更新预览；排队的跨图交接核对操作序号、笔记路径和 epoch，切文档后旧回调不得抢回焦点。

## 交接与布局

`assets/note-live-editor.js` 的 `MermaidBlockWidget` 独立管理展示态 DOM，选择/编辑状态保留在每编辑器 StateField，显式编辑通过内部 effect 交接；源码、选区及历史继续由原 CodeMirror 管理。选中变化调用 `updateDOM()`，复用已挂载的适配器和 SVG。`MermaidEditPreviewWidget` 继续负责源码下的预览，不允许在那里输入或改变源码选区。

展示态复用紧凑块投影，移除两条虚假边界行，外层上下各 4px；图表内层去除重复的纵向 margin/padding，保留水平留白。阅读内层上下各 4px，宽图缩放视口仍保留原功能高度，不以裁切图表来压缩间距。

专项测试发现，原 SVG 出图后仅更新数值缓存不能可靠地使 CodeMirror 高度图失效，导致实际点击“后文”却命中隐藏结束围栏。现在 `measureMermaid()` 在测量写入结束后的微任务中，按实际 CSS 高度更新最多 32 条提示，并发送内部 `mermaidLayoutEffect`。展示及编辑预览的 widget 捕获高度估计值，使当前块高度图失效，同时复用 DOM。回写核对文档、epoch、DOM 和候选状态；没有 `.cm-line` 高度覆盖、正文重建、滚动锁或常驻绘制循环。

原 Worker、缓存预算、字体测量、SVG 清理、阅读高度预留、生命周期和重试机制继续使用。`attach/update/reserve/suspend/resume/destroy` 接口、Markdown 持久化与偏好格式不变；展示、选中及布局通知均不写历史。

## 离线引擎

- 使用 [Pele 1.12.0 官方发行](https://github.com/obsidianmd/pele/releases/tag/1.12.0)，由 npm 官方归档提取未经修改的浏览器包及 MIT 许可证，下载时核对发行元数据的 SHA-512。
- 浏览器包为 730,358 字节，SHA-256 为 `787ed66bb4bd56c15e224109ff5b89ed395ebfacf71fae2c0ccad1f86d6e24ef`；来源和完整性记录同步在 vendor README。
- Worker 与同步回退使用同一包，不新增 npm 构建链或运行时出站。其他工作区的 Mermaid.js 保持原实现。
- 明确提供 `--pele-fg-on-light/dark`，使显式白/黑填充下的标签分别使用深/浅文字；保留原字体、作者样式和测量栈。源码、边数及输出限制和外部资源禁用保持原边界。

## 性能对照

使用 `node tests/note-mermaid-pipeline-performance-browser.js`，默认基线为 `85106e9`，通过独立 URL 分别托管基线/当前的适配器、Worker、Pele、Markdown 和 CSS，避免旧适配器误用新引擎。完整三轮交替执行，与其他浏览器回归分开运行；Edge 1280×900、低动态、实际图表字体，CDP 输入覆盖整个出图过程，每场景每轮至少 8 个输入样本。

完成耗时取三轮中位数，输入 P95 汇总三轮样本，最长任务取最大值；以下均为毫秒。

| 场景 | 1.9.0 / 1.12.0 完成 | 输入 P95 | 最长任务 |
| --- | ---: | ---: | ---: |
| 冷单图 | 99.2 / 98.2 | 2.9 / 3.2 | 0 / 0 |
| 相同内容重开 | 1.5 / 1.8 | 2.1 / 1.9 | 0 / 0 |
| 100 张重复图逐项浏览 | 661.3 / 671.3 | 1.4 / 1.7 | 0 / 0 |
| 100 张不同图逐项浏览 | 755.3 / 738.4 | 1.5 / 1.6 | 0 / 0 |
| 500 节点、3964 边 | 372.3 / 372.7 | 19.7 / 28.1 | 54 / 54 |

同内容重开及 100 张重复图均零解析、零布局。压力图完成时间接近，但输入 P95 增加约 8.4ms；其输入最大值为 51.3 / 47.4ms，样本数为 108 / 85，不能据此宣称新版本全面更快或完全没有长任务。压力图 GC 后主线程/Worker 合计 JS 堆约 9.07 / 9.12MiB；缓存预算仍通过，最后宿主退出后释放 Worker。升级收益以编辑正确性、兼容和深色可读性为主。

原始报告及全部样本由测试输出到系统临时目录，本次最终对照目录为 `relatum-mermaid-pipeline-1V9g7E`。输入探针属于图表承载面，不能当作完整 CodeMirror、整窗启动、进程/GPU 内存或任意大图帧率指标；`0` 长任务只表示未观察到超过 50ms 的任务。
