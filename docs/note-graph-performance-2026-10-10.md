# 笔记图谱标签页与共享引擎验证

日期：2026-10-10 初次移植，2026-10-11 更新透明标签页、标题淡出、生长动画与固定镜头舒展。测试使用本机 Edge、宿主 Playwright 与 bundled Python，所有 API 测试均使用一次性 `RELATUM_DATA_ROOT`，未打开真实笔记库。未重新打包桌面程序。

## 实现与数据边界

笔记工具行的“浏览”后提供图谱入口，以固定特殊身份 `relatum:graph-tab:v1` 在原标签栏维护唯一图谱页，重复点击仅激活，图谱、正文及浏览结果互斥。图谱占满标签栏下的区域，透明背景显示工作区底色，不再使用遮罩、浮窗阴影、透明度、拖动及尺寸控件；右上角保留生长、舒展、复位及笔记本入口，窄窗另有目录入口。范围以左树选中的笔记本为准；默认本排除 `CustomNotebook`，自定义本只扫描自身子树，未选择本时入口禁用，已有图谱标签显示选择提示。每个已有 Markdown 文件都是节点，包括孤立笔记；标题使用完整文件名 stem，随屏幕缩放比例淡出，悬停恢复当前标题并显示完整路径。点击节点激活已有或新建 Markdown 标签，图谱标签保留；失败继续显示图谱。

进入图谱先等待标题/目录改名、候选、表格及内嵌画布交接，保存当前本待保存正文，失败保留原编辑现场。进入图谱临时收起右栏，图谱侧栏只显示笔记本；返回正文恢复原开关及页签，临时状态不写入原笔记本偏好。特殊标签身份参与已有排序、关闭、快捷键和恢复，文件读取/重命名/保存/外部刷新跳过该身份。

`note_graph.py` 专门解析 Wiki、行内及引用式 Markdown 链接。代码、前言、注释、公式、图片、转义示例不参与，列表、引用和表格中的真实链接保留。跨本、缺失、歧义、外部和自引用不生成关系，同一对笔记合并为无向边。原双链面板和移动重写规则保持原语法。

`GET /api/note-graph?root=…[&signature=…]` 复用现有内存增量索引，只保存引用及元数据，不常驻正文。扫描及失效清理限定当前本；无变化复用结果，只有正文变化且拓扑不变时签名也不变。读取不完整返回 `statistics_incomplete`；初次失败显示错误和重试，后台刷新失败保留同本最后一次正确图谱。快速切本在请求前释放旧本数据，避免旧图谱出现在新本标题下。

后端响应缓存上限为 24 本及估算 16MiB，估算为 `(拓扑 JSON UTF-8 字节 + 128 wrapper/signature 字节) × 2`，属于保守预算而非精确 Python 堆测量，不含已有文档索引；超预算的单项可响应但不驻留。标签测量仅按当前图谱缓存，离屏 DOM 回收池最多 256 项，销毁清空全部测量及 DOM。

笔记图谱不再加载 `graph-window.js`，真正查看时才加载共享 GL、引擎及适配器；仅恢复隐藏标签不加载模块、不创建隐藏引擎。切页、浏览结果、离场和页面隐藏立即释放标签、绘制监听器与 GPU/context，迟到响应核对当前本和会话。图谱标签存在时，前端另以 LRU 保留最多 24 本及估算 16MiB 的正确拓扑、节点坐标、相机与待收敛标记，预算为 `(场景 JSON UTF-8 字节 + 128) × 2`，不含活跃绘制资源、DOM 或正文；超大单项不缓存。返回恢复按本视角，拖动后尚未收敛的布局继续有限收敛。成功改名映射受影响会话，删除清理，其他本改名不重建当前图谱。关闭图谱标签或 `pagehide` 清空会话，重启后首次打开重新布局取景；旧 `canvas:noteGraphViews:v1` 不再读取或写入，坐标不写文件、历史或偏好。共享 `restoreView` 校验有限数值、限制缩放并停止旧相机动画，保持相机零实例失效。

解析压力回归还覆盖约 4MiB 的未闭合语法。数学/反引号闭符与 Markdown 目的地、标题闭符通过预索引查询，失败目标不重复扫描全文尾部。重复 `[x](`、平衡外括号但未闭合 `a.md` 引号标题、未闭合角括号目的地，最终隔离样本分别为 1.873、1.900、1.501 秒，均无引用；1/2/4/8KB 重复 `[x](` 为 0.000636/0.000840/0.001751/0.003316 秒。此前该失败目的地路径在 8KB 已达约 1.32 秒，修复后不再呈平方增长。另三组约 4MiB 未闭合数学及不同长度反引号初轮样本为 1.611/1.563/1.256 秒。此为后端首次或真实变化时的解析，非前端交互帧耗时；最坏大文档首次统计仍会等待。路径的 NFC/大小写折叠碰撞视为歧义，不任意选择目标。

## 标题缩放淡出（2026-10-11）

笔记图谱标题现改为随实际 CSS 屏幕比例淡出：`unit ≤ 0.25` 的标题透明度为 0，`unit ≥ 0.65` 为 1，中间以 `t²(3−2t)` 插值。使用屏幕比例而非单独相机 scale，使窄窗和宽窗遵循同一视觉尺度；DPR 不改变 CSS 阈值。完整文字及 12px 字号不变，不再要求远景常显。

## 生长动画、固定镜头与灰阶（2026-10-11）

笔记右上角的魔杖按钮排在舒展前，提供中英文提示。播放先将节点、连线、标题及路径提示隐藏，按播放前完整坐标取景一次，再播种和重启原物理布局。开始生长后保持镜头，连续重播复用该轮初始取景；正常播放结束不补偿。空白等待 100ms，单节点缓动沿用 460ms，节点按数据的稳定顺序出现，间隔为 `min(12ms, 3000ms/(N−1))`，单节点没有错峰。连线透明度沿用两端出现透明度的较小值，标题乘原有缩放及邻域透明度；没有新动画库、定时器或渲染循环。

舒展从点击到收敛保留当前相机坐标和比例。共享引擎的可选 `start({preserveView, introDelayMs, introSpanMs})` 停止旧平移惯性、缩放和取景补间；保留镜头同时禁用启动复位、收敛取景及空视口补偿。复位按钮仍主动取景。未传入新参数的画布和星图保留原启动行为与错峰时序。独立 `onLayoutSettled` 在物理及入场完成后通知宿主，原 `onConverge` 的自动取景语义不变。透明度 ≤ .02 的笔记节点不参与点击命中，其他宿主默认命中规则不变。

浅色节点/悬停为 `#5f5f5f/#202020`，深色为 `#b9b9b9/#f5f5f5`；连线和高亮同步使用中性灰，两种后端的颜色一致，沿用原尺寸、粗细和邻域明暗。空本禁用生长，重播不请求 API、不重建引擎或测量缓存。数据替换取消旧入场；切页、切本、隐藏、关闭和离场释放播放资源，返回沿用坐标和镜头、有限续接未完成布局，完整显示节点而不自动重播。低动态跳过空白、错峰及生长淡入，仍有有限物理收敛。接口、正文和持久化格式不变。

测量发现，远景标题已完全透明时，原标签层仍逐帧写入移动位置和入场透明度。现在保留 DOM、测量和屏外裁剪，只在标题可见或被悬停时补齐这些样式；缓存记录保留最后实际写入值，使第一次重新显示直接定位到最新节点。专项浏览器检查仍确认缩远/放大、隐藏时悬停、完整中文标题和固定字号；追加性能验收比较重新可见标题的实际边界与节点屏幕坐标，确保没有旧位置闪现。
