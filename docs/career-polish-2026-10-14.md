# 生涯黑白打磨与性能验收

日期：2026-10-14。基线为 `82c150e`。保留六个章节和统计内容，仅修改生涯前端、测试与接手文档；没有改动 HTTP 接口、冻结快照、使用统计口径、用户正文或滚动偏好。

## 视觉与图表

生涯使用白色／近黑底面和中性灰，普通图表面板取消外框，紧凑分段筛选与线型图例减少装饰。输入、焦点、表格与图谱仍保留必要的边界和提示。参考 [Apple 图表设计](https://developer.apple.com/videos/play/wwdc2022/110340/)的清晰刻度与适度网格，以及 [Apple 动效指南](https://developer.apple.com/design/human-interface-guidelines/motion)的短反馈和可打断过渡，按本项目阅读场景调整。

- 时长轴按实际最大值统一选择秒、分钟、小时；采用易读步长并据此确定精度。147 秒不会再得到五个“0”，数量轴使用整数。提示和明细保留原毫秒值。
- 多系列使用灰阶与对应线型；日期缺口继续断开。超过 90 日时不创建中间圆点 DOM，完整路径、孤立点与最近真实值命中保留。365 日连续样本保留 364 段连接，中间圆点 DOM 为 0；稀疏样本继续支持逐点键盘聚焦。
- 标题用 6px、约 300–380ms 的有限淡入；控件反馈约 160–180ms，图表首次展开约 700–900ms、错峰至多 160ms，回看 240ms。600ms 页面淡入及 1500ms 数字累计保持原规则，低动态立即完成。
- 图表初始占位根据 SVG 比例、排名行数及图谱控件预留；挂载恢复自然高度，卸载保留实测值。窗口宽度改变作废旧像素占位，空范围恢复空图尺寸。绘图区使用普通块布局，SVG 字号通过 CSS 断点补偿，避免额外的测量／改样式／再测量。

## 数据与生命周期

`assets/career/data.js` 按冻结对象身份缓存实体、分组排序和合并采集区间，只保留当前范围投影；实际记录边界一次准备，完整覆盖相同记录的不同范围复用汇总。区间查询二分定位，按本地午夜计算，覆盖夏令时的 23／25 小时日。排名、月份、星期、小时及操作汇总由当前投影共用，原始报告不修改。

`chapters.js` 局部更新历史图表，保留章节、筛选控件、库存图表及图谱实例；相同条件不写 DOM。主题只更新必要底图与图谱配色，语言重建复用数据及展示身份，隐藏时发生的主题／语言变化在返回时处理。精确明细的展开、页数和内部滚动在卸载后恢复。

`lifecycle.js` 直接检查实际工作区状态。切换开始先停调度、悬停和手势，保留退场中的静态绘制；外层隐藏时释放引擎、Canvas 与 tooltip。清理不等待下一工作区初始化。快速反转保留原引擎和镜头，最小化、隐藏及 pagehide 立即释放，后台生成继续沿用原任务协议。

## 后续补改：重新生成与字号

点击生成或重新生成时，立即将报告滚动区设为 inert 并隐藏内容与滚动条，显示干净的主题底色，同时回到顶部、暂停调度和图表。后台任务完成且新快照读取成功后重建报告，从顶部播放 600ms 淡入；数字仍等待 200ms 后开始原 1500ms 累计。等待期间切页、隐藏、最小化以及语言变化不挂载旧图表，返回继续同一任务。失败时恢复旧报告、阅读锚点并显示错误；低动态直接显示结果。取消的轮询不得提交迟到的状态或错误。

按照用户提供的 Apple 页面截图强化字号层级：桌面主标题最高 120px、章节标题 72px、图表标题 34px，字重为 700–760；主说明为 18–21px，图表说明 14px，统计标签 13–14px。窄窗另用 clamp 和断点缩小标题，排名占位同步新的行高，不增加字体下载或逐图测量。

用户要求此轮只做基础代码检查，因此后续补改仅执行 JavaScript 语法、CSS 括号和 Git 差异检查，没有重跑浏览器、性能或后端回归。下方实测及 JSON 记录均来自此前的整体打磨阶段，不代表后续生成流程和字号调整已完成运行验收。

## 三轮对照

无头 Edge 155.0.4283.45；1440×1000，普通 DPR 1，压力 DPR 2／CDP CPU 四倍。复用隔离的 5000 篇笔记、500 张画布、200 个研究页、10 万条计时输入产生的冻结快照。测量时串行运行浏览器。

`career-polish-browser.js --performance` 在 12 秒内按实际经过时间走完整份报告，避免每显示帧固定推进造成高刷新率下速度不同。采样为 RAF 回调间隔，并非 GPU 呈现时间。改版前后滚动距离分别为 13582／13794px，保留尺寸差异供判断。

| 固定时间滚动 P95 | 修改前三轮（ms） | 修改后三轮（ms） | 目标 |
| --- | --- | --- | --- |
| 普通 | 4.3 / 4.3 / 4.3 | 4.3 / 4.3 / 4.3 | ≤20ms |
| 压力 | 12.6 / 12.6 / 12.6 | 12.5 / 12.4 / 12.4 | ≤35ms |

六次筛选为 30／90／自然年／全部／30／全部。普通组合的 18 次调用中位数由 10.55ms 到 7.55ms，压力组合由 27.25ms 到 20.50ms。本样本中，自然年／全部实际覆盖相同记录，修改后的调用分别约 0.6–1.4／0.3–0.5ms，压力下约 1.6–3.0／0.7–1.7ms。不同数据分布的收益会不同，不能推导为所有筛选均提速同样比例。

每轮六次筛选的库存面板及报告 shell 替换次数由 6／6 到 0／0。七个日期的合计与笔记采集状态查询，旧实现调用 coverage.filter／sort 各 70 次，新实现日期查询各 0 次；排序已移至一次性区间准备。同尺寸热力图仍仅绘制 365 格，同格提示文字重复写入为 0。普通滚动 P95 基本持平，不能声称整体帧率大幅提高。

完整外壳另用相同的暖缓存隔离目录，对照原 180 显示帧滚动和真实节点拖动流程：

| 完整外壳 P95 | 修改前三轮（ms） | 修改后三轮（ms） |
| --- | --- | --- |
| 普通滚动 | 8.3 / 4.4 / 4.3 | 8.3 / 4.3 / 4.3 |
| 压力滚动 | 16.8 / 16.7 / 16.8 | 20.7 / 16.8 / 16.7 |
| 普通拖动与悬停 | 4.3 / 4.3 / 4.3 | 4.3 / 4.3 / 4.4 |
| 压力拖动与悬停 | 8.4 / 8.5 / 8.5 | 12.4 / 8.5 / 8.5 |

首轮仍有准备开销，稳定轮次基本持平。开发中的逐 SVG ResizeObserver 字号测量和列向 Flex 绘图区曾出现压力超标，已移除；失败样本作为被替代实现保留在 JSON，不放宽门槛，也不将多次波动完全归因于某一单项调整。

## 首轮回归（后续补改前）

- 六组后端共 54 项通过；生涯契约、使用采集、共享实例缓存、数字及新增静态回归通过。
- 图表交互的 WebGL／Canvas2D 两组通过；覆盖全部图表、精确提示、图例 DOM 复用、真实节点／关系命中、深浅主题、窄窗和低动态。
- 数字浏览器专项通过：启动约 200ms、15% 阈值、宽窄窗尺寸、隐藏／最小化、重新生成和闲置零 RAF。初次图谱挂载曾把后续指标下推约 43px，已修正占位并通过原阈值检查。
- 新专项通过：库存引擎、Canvas、shell、控件焦点及明细页复用；重复条件零 DOM 更新；主题不改镜头；快速反转取消未完成手势；下一工作区模拟延迟 1.2 秒，退场 350ms 后释放而不等待它；隐藏期间语言变化、旧宽度占位失效、密集真实路径及低动态。
- `career-v2-browser.js --large` 最终 32 项流程通过，普通滚动 P95 8.4／8.3／8.2ms，压力滚动 29.2／25.2／25.0ms；普通交互 4.3／4.3／4.3ms，压力交互 16.7／16.5／16.6ms。原 20／35ms 门槛通过，静置及收敛后新增 RAF 为 0，浏览器异常为 0。个别最长帧仍到约 66.6ms，P95 达标不等于消除所有掉帧。
- 真实 WebView2 默认与强制 Canvas2D 的 `--checks-only` 均通过，包含原生最小化／还原、资源释放及重新生成；此模式不采压力帧率。资源生命周期默认与 `--on-demand` 两组通过，关闭 GPU buffer、暂停音源及关闭／过期 PCM 计数均为 0。

原 v2 测试曾以未限定的 `[data-start-workspace]` 命中 html／body，并用固定等待假定下一工作区已初始化。现在限定按钮、分别等待隐藏及切换事件；首次展示以属性变化验证，避免截图耗时跨过动画结束而误判。

原始样本保存在 [验收 JSON](career-polish-2026-10-14.json)，已去除临时数据根路径。生成耗时受首次 SQLite 索引准备影响，本轮没有修改后端索引，也不将其变化计为 UI 性能收益。
