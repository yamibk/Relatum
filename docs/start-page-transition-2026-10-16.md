# 画布工作区页面切换与书脊图标：2026-10-16

## 确认的问题

此前 `a2b1e41` 优化了侧栏输入合并与读写顺序，其性能场景是隔离书脊，不能覆盖日历、热力图等完整页面的交接。

这次在一次性数据目录中运行真实首页，先预热各页，再采集完整切换的 Chromium trace：

- 活跃页的年度热力图为 365/366 个 SVG 格子分别创建带延迟的位移、缩放、透明度动画。重新进入会重播；离开时 `getAnimations({subtree:true})` 再逐个暂停，单次点击出现约 27ms 同步任务。
- 日历离页也遍历 CSS/WAAPI 动画；右栏重播甚至逐个后代调用 `getAnimations()`。这些 API 会在已有 DOM 写入后结算样式。日历切复习的同步点击三轮中位数为 21.6ms。
- 空的跨页便签层也反复读取宿主 computed position、scrollHeight 与边界；星图释放计时读取根节点 computed style。它们会把新页面样式/布局工作提前带入同一点击。
- 未选中的书脊按钮有独立低层叠放上下文，图标即使有较高 z-index 也无法越过黑色实体。实体途经“日”等图标会把它们盖掉。暂停真实 transform 过渡并截图可以复现，无需日历图标自身有动画。

## 改动

- 保留完整日期 DOM、色阶、逐格鼠标/键盘操作和星图生命周期。年度热力图只让七个连续周区段错峰淡入，外层卡片继续原有入场；取消逐格位移与缩放。区段保持原日期 DOM 顺序，Tab 仍按时间前进。
- 活跃和日历的 CSS 入场由局部冻结类暂停；外层退场继续播放，收尾或快速返回按原身份清理。日历只记录自己创建的右栏 WAAPI 句柄，完成后取消已无必要的填充效果；重播不扫描整个子树。未激活的日历不重复冻结。
- 日历缓存重进且上次交接已完成时，在显示外层前直接准备入场。快速返回仍保留原中断重播路径，避免同帧清类/加类没有真正重置动画。
- 空便签页不读取边界，已有宿主不重复读取 computed position；创建便签及有内容页面仍按实际尺寸处理。星图释放计时读取两个首页壳已经写入的内联速度值。
- 书脊按钮不建立叠放上下文，图标一直在实体上方；悬停、按下只移动图标，按钮命中尺寸稳定。实体颜色、形状、独立速度、彩色悬停层及低动态规则保留。

没有新依赖、API、偏好或持久化字段。未改后端与真实用户数据。

## 日历离页闪烁复查

用户在 `d4de03a` 后仍报告“从日历切任意页面，日字稳定闪烁”。上次验证了滑块经过未选中入口的遮挡，没有直接验证离开当前页时的文字前景，因此不能据此声称覆盖了这条路径。

复查确认发布包 `start.js/styles.css` 与该提交的源码哈希一致。使用同一发布 EXE、自建数据根和浏览器配置，通过 WebView2 调试接口采集原生合成帧，同时记录字形文本、坐标、颜色、透明度与 DOM 变化：

- 字形 DOM、位置和透明度保持不变。问题来自按钮的 `color 180ms` 过渡：黑色实体已经移走，字仍接近白色；日历切复习的实际截图出现字形最暗值约 225、背景约 252，仅约 27 级亮度跨度，随后才恢复灰色。只关闭离页变色的 A/B 测试消除了这段低对比帧，无需替换字体、图标或渲染引擎。
- 浅色未选中入口现在立即使用正常前景色；选中入口仍保留原变色、黑块仍按原速度滑动。深色保持原有颜色过渡。
- 页面进场使用 24 层，原导航只有 20 层；1280px 场景中，活跃页年份圆点会在进场期间叠到日历入口上。导航升至 30 层，进退场内容继续使用原 23/24 层。

最终专项验收检查日历到复习、活跃、速记、树状、学习、专注六页，另用复习离页作对照；每次切换同一任务断言离页颜色已经恢复，并检查截图字形区域至少 70 级亮度跨度（浅色）、DOM 未替换及导航始终高于页面。截图坐标按实际 PNG/CSS 尺寸比例映射，不能把 WebView2 的 1920×1350 位图直接当成 1280×900 CSS 像素。默认使用用户此次的 457ms 滑块速度；另测 100ms 边界与深色过渡兼容。

`RELATUM_SPINE_RELEASE` 指向已有发布目录时，只把工作区 CSS 拦截到隔离原生会话，不改发布文件或真实用户数据。`RELATUM_GLYPH_BASELINE_REF=d4de03a` 可载入旧 CSS，断言旧版确实仍保留错误的离页前景；默认断言修复后的行为。`RELATUM_GLYPH_THEME` / `RELATUM_GLYPH_SPEED` 可指定主题与滑块速度。`--glyph-frames` 保存全部合成帧，否则只保存首尾帧及 JSON 数据。PNG 分析使用测试宿主已有的 `pngjs`，不增加应用依赖。

## 上一轮页面性能测量（d4de03a）

Edge 155.0.4283.45，无头模式，1600×1000、DPR 1、浅色，基线 `927dbe5`。隔离库为空，年度热力图仍有 365 个日期。每次预备页停留 1700ms，采集点击后 900ms，包含滑块和页面交接；各场景先基线三轮、再当前三轮。下表为最终实现的 `--top-only` 三轮中位数，单位 ms；任务耗时为 CDP TaskDuration 差值，不是整段墙钟时间。

热力图动画与逐帧布局明显减少，日历和活跃切往复习的同步交接也减少。部分工作移到了首个显示帧；日历切活跃仍有约 28ms 同步工作，活跃切复习的 Layout 次数基本不变。Paint 也有上涨：例如日历切活跃为 9.5 → 13.2ms、活跃切复习为 25.9 → 30.2ms，不能声称所有指标都下降或每次切换都已满帧。无头浏览器的 RAF 频率及 Paint 记录不能换算为物理显示器/WebView2 帧率、GPU 栅格化成本或整机 CPU 占用。
